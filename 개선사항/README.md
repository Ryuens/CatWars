# 개선사항 관리

이 폴더에서 프로젝트 개선사항을 관리합니다.

## 개선사항 작성 방법

각 개선사항은 마크다운 파일로 작성합니다.

### 파일명 규칙
- `YYYYMMDD-제목.md` (예: `20251119-로그인-기능-개선.md`)

### 템플릿

```markdown
# 제목

## 현재 상태
- 현재 동작 방식 설명

## 개선 목표
- 달성하고자 하는 목표

## 상세 내용
- 구체적인 개선 내용

## 우선순위
- [ ] 높음
- [ ] 중간
- [ ] 낮음

## 관련 문서
- 관련 문서 링크
```

## 상태 관리

- `할일/` - 예정된 개선사항
- `진행중/` - 진행 중인 개선사항
- `완료/` - 완료된 개선사항
