# CatWars

프로젝트 문서화 및 개선사항 관리를 위한 저장소입니다.

## 디렉토리 구조

```
CatWars/
├── 문서/                    # 프로젝트 문서
│   ├── 요구사항/            # 요구사항 문서
│   ├── 디자인/              # 디자인 문서 및 스펙
│   └── 아키텍처/            # 아키텍처 문서
├── 에셋/                    # 디자인 에셋
│   ├── 이미지/              # 이미지 파일
│   └── 목업/                # 목업/와이어프레임
└── 개선사항/                # 개선사항 및 TODO
```

## 문서 업로드 가이드

### 문서 파일
- 요구사항 문서: `문서/요구사항/`
- 디자인 스펙: `문서/디자인/`
- 아키텍처 문서: `문서/아키텍처/`

### 디자인 파일
- 이미지 (PNG, JPG, SVG 등): `에셋/이미지/`
- 목업/와이어프레임: `에셋/목업/`

### 개선사항
- 개선 제안 및 TODO: `개선사항/`

## 시작하기

1. 기존 프로젝트 문서를 해당 디렉토리에 업로드
2. `개선사항/` 폴더에서 개선사항 관리
3. 변경사항은 커밋과 함께 기록
