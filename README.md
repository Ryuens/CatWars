# CatWars

프로젝트 문서화 및 개선사항 관리를 위한 저장소입니다.

## 디렉토리 구조

```
CatWars/
├── docs/                    # 프로젝트 문서
│   ├── requirements/        # 요구사항 문서
│   ├── design/              # 디자인 문서 및 스펙
│   └── architecture/        # 아키텍처 문서
├── assets/                  # 디자인 에셋
│   ├── images/              # 이미지 파일
│   └── mockups/             # 목업/와이어프레임
└── improvements/            # 개선사항 및 TODO
```

## 문서 업로드 가이드

### 문서 파일
- 요구사항 문서: `docs/requirements/`
- 디자인 스펙: `docs/design/`
- 아키텍처 문서: `docs/architecture/`

### 디자인 파일
- 이미지 (PNG, JPG, SVG 등): `assets/images/`
- 목업/와이어프레임: `assets/mockups/`

### 개선사항
- 개선 제안 및 TODO: `improvements/`

## 시작하기

1. 기존 프로젝트 문서를 해당 디렉토리에 업로드
2. `improvements/` 폴더에서 개선사항 관리
3. 변경사항은 커밋과 함께 기록
