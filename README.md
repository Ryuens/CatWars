# CatWars (캣워즈)

모바일 전략 디펜스 게임 프로젝트 문서화 및 개선사항 관리 저장소입니다.

## 디렉토리 구조

```
CatWars/
├── 0_참고자료/            # 기존 프로젝트 원본 자료
│   └── 원본자료/          # 업로드된 원본 파일들
├── 0_개선사항/            # 개선사항 및 확장 콘텐츠 관리
├── 1_개요/                # 게임 개요, 코어루프, 핵심 요약
├── 2_시스템기획/          # 게임 시스템 기획 문서
└── 3_데이터테이블/        # 데이터 테이블 설명 및 스펙
```

## 게임 개요

CatWars는 타워 디펜스 기반의 전략 게임으로, 다양한 종족의 유닛을 소환하여 적군 기지를 파괴하는 것이 목표입니다.

### 주요 시스템
- **전투 시스템**: 유닛 소환, 스킬 사용, 자동 전투
- **성장 시스템**: 스킬 강화, 특성(Mastery), 유물
- **던전 시스템**: 슬라임 러쉬(Dr.Chur), 마계침공
- **경제 시스템**: 골드, 마석, 파랑수정, 특성석
- **상점 시스템**: 패키지, 배틀패스, 일일 보상
