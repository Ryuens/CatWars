# 스킬 시스템

## 스킬 구조

- 총 160개 스킬 (레벨별)
- 레벨별 계수(Value) 적용

---

## 스킬 데이터

| 필드 | 설명 |
|------|------|
| Idx | 스킬 인덱스 |
| Lv | 스킬 레벨 |
| Value | 스킬 계수 |
| SkillName | 스킬 이름 |
| SkillDesc | 스킬 설명 |
| RequireExp | 필요 경험치 |

---

## 스킬 초월

스킬을 초월하면 추가 능력치를 획득합니다.

| 필드 | 설명 |
|------|------|
| Skill_U_StatType | 초월 시 추가되는 능력치 타입 |
| U1_Value | 1초월 시 레벨별 능력치 |
| U2_Value | 2초월 시 레벨별 능력치 |
| U3_Value | 3초월 시 레벨별 능력치 |

### 초월 단계
1. **1초월**: U1_Value 적용
2. **2초월**: U2_Value 적용
3. **3초월**: U3_Value 적용

---

## 스킬 비용

- 레벨별 필요 스킬 재료량 설정
- SkillCost.xlsx에서 관리

---

## 스킬 강화 흐름

1. 스킬 재료 수집
2. 스킬 레벨업 (Value 증가)
3. 최대 레벨 도달 시 초월 가능
4. 초월 시 추가 능력치 획득
