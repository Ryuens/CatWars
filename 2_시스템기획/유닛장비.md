# 유닛 장비

## 개요
각 유닛에 장비 1개를 장착하여 영구적인 능력치 강화를 제공하는 시스템. 진화해도 장비가 유지되어 성장의 연속성을 보장한다.

---

## 핵심 특징

- **유닛당 1개 장비 슬롯**
- 장비 소환(뽑기)으로 획득
- 중복 장비로 레벨업 강화
- 진화 시스템 (별 상승)
- 진화해도 장비 효과 유지
- 영구 성장 시스템
- 특수 효과 (고급 장비)

## 장비 분류별 특징

### 공격형 (_01)
- **핵심 스탯**: UNIT_DMG, CRIT_RATE, CRIT_DMG, ATTACK_SPEED
- **용도**: 딜러 유닛에게 최적화
- **특수 효과**: 추가 타격, 전쟁의 일격

### 방어형 (_02)
- **핵심 스탯**: UNIT_HP, DEFENSE, UNIT_DMG, MOVE_SPEED
- **용도**: 탱커, 지원 유닛에게 최적화
- **특수 효과**: 보호막, 무적

### 속도형 (_03)
- **핵심 스탯**: ATTACK_SPEED, MOVE_SPEED, CRIT_RATE, UNIT_DMG
- **용도**: 기동성 유닛에게 최적화
- **특수 효과**: 회피 시 공속/이속 버프

### 특수형 (_04)
- **핵심 스탯**: UNIT_DMG, CRIT_DMG, UNIT_HP, CRIT_RATE
- **용도**: 마법/기술 유닛에게 최적화
- **특수 효과**: 추가 피해, 체력 회복

### 균형형 (_05)
- **핵심 스탯**: 모든 스탯 골고루 분배
- **용도**: 범용 유닛에게 최적화
- **특수 효과**: 방어력 무시, 전체 스탯 증가

## 장비 강화 시스템

### 레벨업 (중복 장비 + 골드)
```
동일 장비 획득 시 재료로 축적
업그레이드 버튼으로 레벨업

레벨업 필요 개수:
Lv 1→2: 중복 1개 + 골드 1,000
Lv 2→3: 중복 2개 + 골드 2,000
...
Lv 99→100: 중복 99개 + 골드 99,000

총 필요 개수: 중복 4,950개
```

| 1 | 1.00x | 0 | 0 |
| 10 | 1.45x | 45 | 45,000 |
| 25 | 2.20x | 300 | 300,000 |
| 50 | 3.45x | 1,225 | 1,225,000 |

## 장비 진화 시스템

### 별 상승 (★ → ★★★★★)

장비는 5성까지 진화할 수 있으며, 진화 시 효과가 크게 증가합니다.

### 진화 재화

| 재화 | 획득 방법 |
|------|----------|
| 마법석 | 장비 분해 시 획득 |
| 상급석 | 마법석 50개로 제작 |

### 장비 분해

| 등급 | 마법석 획득량 |
|------|--------------|
| 일반 | 5개 |
| 희귀 | 30개 |
| 에픽 | 100개 |
| 전설 | 500개 |

### 진화 비용

| 진화 단계 | 필요 재료 | 비고 |
|----------|----------|------|
| ★ → ★★ | 자동 (레벨 25) | 레벨업으로 해금 |
| ★★ → ★★★ | 자동 (레벨 50) | 레벨업으로 해금 |
| ★★★ → ★★★★ | 상급석 15개 | 수동 진화 필요 |
| ★★★★ → ★★★★★ | 상급석 25개 | 수동 진화 필요 |

### 별 등급별 효과

| 별 등급 | 효과 배율 | 달성 조건 |
|---------|----------|----------|
| ★ | 1.0x | 기본 |
| ★★ | 1.3x | 레벨 25 |
| ★★★ | 1.6x | 레벨 50 |
| ★★★★ | 2.0x | 레벨 75 + 상급석 15 |
| ★★★★★ | 2.5x | 레벨 100 + 상급석 25 |

**최종 효과 = 기본 효과 × 레벨 배율 × 별 배율**

예: 전설 공격력 장비 (기본 ATK +25%)
- Lv.100 ★★★★★ = 25% × 6.0 × 2.5 = 375%

## 계산 예시

### 전설 공격 장비 최종 효과

**T4_01: 고양이 왕의 전쟁 유물 (기본 스탯)**

- CRIT_RATE +15%
- CRIT_DMG +35%

**필요 재료**
- 중복 장비: 4,950개
- 골드: 4,950,000
- 상급석: 40개 (★★★★ 15 + ★★★★★ 25)
- 마법석 환산: 2,000개 (상급석 40개 × 50)

## 특수 효과 상세

### 공격형 특수 효과

**T3_01 (에픽)**: 8% 확률로 추가 타격

**T4_01 (전설)**: 10% 확률 전쟁의 일격

**T3_02 (에픽)**: 피격 시 6% 확률로 보호막
- 공격받을 때 6% 확률로 2초간 피해 무효

**T4_02 (전설)**: 15% 확률로 3초간 무적
- 공격받을 때 15% 확률로 3초간 모든 피해 무효

**T3_03 (에픽)**: 회피 시 2초간 공속 +15%
- 공격 회피 성공 시 2초간 공격속도 15% 증가

### 특수형 특수 효과

**T3_04 (에픽)**: 10% 확률로 추가 피해 +40%

**T4_04 (전설)**: 타격 시 체력 회복 +2%
- 일반 공격 시 자신의 최대 체력 2% 회복

### 균형형 특수 효과

**T3_05 (에픽)**: 공격 시 5% 확률로 방어력 무시
- 일반 공격 시 5% 확률로 적의 방어력을 무시하고 피해
