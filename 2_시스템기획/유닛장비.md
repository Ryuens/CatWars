# 유닛 장비 시스템

## 개요
유닛에 장비를 장착하여 영구적인 스탯 버프를 제공하는 시스템. 진화해도 장비 효과가 유지되어 성장 연속성을 보장한다.

---

## 핵심 컨셉

### 위아워리어 참고 포인트
- 진화해도 초기화되지 않는 영구 장비
- 유닛별 장비 슬롯
- 장비 강화 및 합성 시스템
- 장비 소환을 통한 획득

---

## 장비 슬롯 구조

### 유닛별 장비 슬롯
```
[유닛 장비 슬롯]
┌─────────────────────────────┐
│  유닛 1 (근거리)            │
│  ┌───┐ ┌───┐ ┌───┐ ┌───┐   │
│  │ 🗡️│ │🛡️│ │👑│ │💎│   │
│  └───┘ └───┘ └───┘ └───┘   │
│  무기   방어구  투구   악세   │
└─────────────────────────────┘
```

### 슬롯 타입
| 슬롯 | 타입 | 주요 스탯 |
|------|------|----------|
| 1 | 무기 (Weapon) | 공격력, 치명타 |
| 2 | 방어구 (Armor) | 체력, 방어력 |
| 3 | 투구 (Helmet) | 체력, 공격속도 |
| 4 | 악세서리 (Accessory) | 복합 스탯 |

### 슬롯 해금 조건
| 슬롯 | 해금 조건 |
|------|----------|
| 무기 | 기본 해금 |
| 방어구 | 타임라인 레벨 2 |
| 투구 | 타임라인 레벨 5 |
| 악세서리 | 타임라인 레벨 10 |

## 장비 등급

### 등급 체계
| 등급 | 색상 | 기본 스탯 배율 | 획득 확률 |
|------|------|---------------|----------|
| 일반 (Normal) | 회색 | 1.0x | 40% |
| 고급 (Rare) | 녹색 | 1.5x | 30% |
| 희귀 (Epic) | 파랑 | 2.0x | 20% |
| 전설 (Legendary) | 보라 | 3.0x | 8% |
| 신화 (Mythic) | 주황 | 5.0x | 2% |

### 등급별 특성
```
[일반]
- 기본 스탯만 제공

[고급]
- 기본 스탯 + 보조 스탯 1개

[희귀]
- 기본 스탯 + 보조 스탯 2개

[전설]
- 기본 스탯 + 보조 스탯 2개 + 세트 효과

[신화]
- 기본 스탯 + 보조 스탯 3개 + 세트 효과 + 특수 능력
```

## 장비 강화 시스템

### 강화 레벨
| 레벨 | 스탯 증가 | 성공 확률 | 비용 (골드) |
|------|----------|----------|-------------|
| +1 | +5% | 100% | 100 |
| +2 | +10% | 100% | 200 |
| +3 | +15% | 100% | 400 |
| +4 | +20% | 90% | 800 |
| +5 | +25% | 80% | 1,600 |
| +6 | +30% | 70% | 3,200 |
| +7 | +35% | 60% | 6,400 |
| +8 | +40% | 50% | 12,800 |
| +9 | +45% | 40% | 25,600 |
| +10 | +50% | 30% | 51,200 |

### 강화 재료
```
[등급별 강화 재료]
일반~고급: 강화석
희귀~전설: 고급 강화석
신화: 신화 강화석

[강화 재료 소모량]
+1~3: 1개
+4~6: 2개
+7~9: 3개
+10: 5개
```

### 강화 실패 보호
- +6 이상 강화 실패 시 레벨 유지 (하락 없음)
- 축복의 주문서: 성공 확률 +10%
- 보호 주문서: 실패 시 재료만 소모

## 장비 합성 시스템

### 등급 합성
```
[합성 공식]
같은 등급 장비 3개 → 상위 등급 장비 1개 (랜덤)

[예시]
일반 무기 x3 → 고급 무기 1개
고급 방어구 x3 → 희귀 방어구 1개
희귀 투구 x3 → 전설 투구 1개
전설 악세 x3 → 신화 악세 1개
```

### 선택 합성
```
[조건]
- 마석 100 추가 소모
- 원하는 슬롯 타입 선택 가능

[예시]
고급 무기 x3 + 마석 100 → 희귀 무기 1개 (확정)
```

### 분해
```
[분해 보상]
일반: 강화석 x1
고급: 강화석 x3
희귀: 고급 강화석 x1
전설: 고급 강화석 x3
신화: 신화 강화석 x1
```

```

고급 소환: 마석 150 (10회: 마석 1,350)

[일반 소환 확률]
일반: 50%
고급: 35%
희귀: 12%
전설: 2.5%
신화: 0.5%

[고급 소환 확률]
고급: 45%
희귀: 35%
전설: 15%
신화: 5%
```

### 천장 시스템
```
[보장 시스템]
50회 소환: 전설 확정
100회 소환: 신화 확정
```

```

- 광고 시청 소환권

[이벤트]
- 출석 보상
- 미션 보상
```
