# 유닛 장비

## 개요
각 유닛에 장비 1개를 장착하여 영구적인 능력치 강화를 제공하는 시스템. 진화해도 장비가 유지되어 성장의 연속성을 보장한다.

---

## 핵심 특징

- **유닛당 1개 장비 슬롯**
- 장비 소환(뽑기)으로 획득
- 중복 장비 획득 시 자동 강화
- 진화해도 장비 효과 유지
- 영구 성장 시스템

---

## 장비 슬롯 구조

```
┌─────────────────────────────────┐
│  유닛 1 (신석기 전사)           │
│                                 │
│       ┌───────┐                 │
│       │  🗡️   │                 │
│       │ Lv.25 │                 │
│       └───────┘                 │
│       화염검                    │
│       공격력 +20%               │
└─────────────────────────────────┘
```

### 장비 효과 타입 (10종)
| 효과 | 설명 |
|------|------|
| 공격력 | 유닛 공격력 증가 |
| 체력 | 유닛 체력 증가 |
| 공격속도 | 공격 주기 감소 |
| 치명타 | 치명타 확률/피해 증가 |
| 골드 획득 | 골드 획득량 증가 |
| 소환석 생산 | 소환석 생산량 증가 |
| 스킬 쿨타임 | 스킬 쿨타임 감소 |
| 보스 피해 | 보스에게 추가 피해 |
| 기지 체력 | 기지 체력 증가 |
| 모든 스탯 | 전체 능력치 증가 |

| 일반 | 회색 | 1% | 100 | 50% |

| 전설 | 주황 | 12% | 100 | 1% |

### 레벨업 효과
```
레벨 1: 기본 효과
레벨 10: 기본 효과 × 1.5
레벨 50: 기본 효과 × 3
레벨 100: 기본 효과 × 5
```
