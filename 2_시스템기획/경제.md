# 경제 시스템

## 재화 종류

| 재화 | 타입 | 주요 용도 |
|------|------|-----------|
| 골드 | GOLD | 업그레이드, 유닛 해금 |
| 마석 | GEM | 프리미엄 재화 |
| 파랑수정 | BLUECRYSTAL | 특수 구매 |
| 특성석 | MASTERYGEM | 특성 업그레이드 |

---

## 골드 획득

### 1. 유닛 처치
- 시대별, 유닛별 골드량 차등
- GetStageGold.xlsx에서 관리

### 2. 적 기지 타격
- HP당 획득 골드 계산:
```
HP당 골드 = EnemyBaseCampGetGold / EnemyBaseCampHp
```
- 아군 유닛이 가격할 때마다 피해 HP에 비례해서 골드 획득

### 적 기지 골드 데이터
- 1~6시대 획득량 (월드별 획득량은 반복)

## 골드 사용처

| 용도 | 설명 |
|------|------|
| 기지 업그레이드 | 기지 HP 증가 |
| 소환석 업그레이드 | 생산량 증가 |
| 유닛 해금 | Unit2, Unit3 해금 |
| 시대 이동 | EvolutionCost |
