# 특성 시스템 (Mastery)

## 구조

- 총 95개 특성
- 760개 레벨 데이터
- 4개 특성 데이터 타입

---

## 특성석

### 획득처
- 마계침공 던전에서 획득

### 용도
- 특성 업그레이드에 사용

---

## 특성 데이터

| 파일 | 설명 |
|------|------|
| Mastery.xlsx | 특성 기본 정보 (95개) |
| MasteryData.xlsx | 특성 타입 정의 (4개) |
| MasteryLevel.xlsx | 특성 레벨 데이터 (760개) |

---

## 특성 강화

1. 특성석 수집 (마계침공 던전)
2. 특성 선택
3. 특성석 소모하여 레벨업
4. 영구 스탯 증가

---

## 특성 효과

- 영구 스탯 증가
- 전투 능력 강화
- 특정 콘텐츠 보너스
