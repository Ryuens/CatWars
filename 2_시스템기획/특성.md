# 특성 시스템

## 개요
특성석을 사용하여 영구적인 능력치 보너스를 획득하는 시스템. 총 95개 특성으로 구성.

---

## 핵심 특징

- 특성석으로 업그레이드
- 영구 스탯 증가
- 4가지 특성 카테고리
- 레벨당 효과 증가

---

## 특성석

### 획득처
| 획득처 | 획득량 | 설명 |
|--------|--------|------|
| 츄르박사의 실험실 | 10~100 | 던전 클리어 보상 |
| 일일 퀘스트 | 20 | 매일 완료 보상 |
| 업적 달성 | 50~500 | 일회성 보상 |
| 이벤트 | 다양 | 기간 한정 |

### 일일 예상 획득량
```
일일: 100~200개
주간: 700~1,400개
```

## 특성 강화 비용

### 레벨별 필요 특성석
| 레벨 | 필요량 | 누적 필요량 |
|------|--------|------------|
| 1→2 | 10 | 10 |
| 2→3 | 20 | 30 |
| 3→4 | 40 | 70 |
| 4→5 | 80 | 150 |
| 5→6 | 160 | 310 |
| 6→7 | 320 | 630 |
| 7→8 | 640 | 1,270 |
| 8→9 | 1,280 | 2,550 |
| 9→10 | 2,560 | 5,110 |

### 예상 소요 기간
```
1개 특성 만렙: 약 1개월
전체 특성 만렙: 약 8년+
```

---

## 특성 효과 계산

### 최종 효과
```
최종 효과 = 레벨 × 레벨당 증가량

예시: 공격력 강화 Lv.10
효과 = 10 × 2% = 20%
```

### 전체 보너스
```
공격 특성 총 보너스: 최대 +100%
방어 특성 총 보너스: 최대 +80%
유틸 특성 총 보너스: 최대 +50%
```
