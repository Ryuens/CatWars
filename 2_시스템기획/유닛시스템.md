# 유닛 시스템

## 종족 구성

- 총 37개 종족
- 각 종족당 3개 유닛 구성
- 스테이지별 종족 인덱스 할당

---

## 종족 데이터 구조

| 필드 | 설명 |
|------|------|
| TribeIndex | 종족 인덱스 |
| SetInStage | 배치되는 시대 |
| TribeUnit1_Index | 1번 유닛 인덱스 |
| TribeUnit2_Index | 2번 유닛 인덱스 |
| TribeUnit3_Index | 3번 유닛 인덱스 |
| TribeTitle | 종족 이름 |
| TribeTime | 종족 시간 |
| TribeDesc | 종족 설명 |

---

## 유닛 해금

### 해금 비용

| 유닛 | 비용 |
|------|------|
| Unit1 | 기본 해금 |
| Unit2 | 스테이지별 골드 (Unit2_OpenCost) |
| Unit3 | 스테이지별 골드 (Unit3_OpenCost) |

### 시대 이동
- **EvolutionCost**: 시대 이동 비용

---

## 유닛 소환 비용

### 구조
- 타임라인(타임라인)별 유닛 소환 비용 차등
- 시대별, 유닛별 개별 비용 설정

### 데이터 형식
```
Chapter: 타임라인 인덱스
Stage1_Unit1_Cost: 시대1의 첫번째 유닛 소환비용
```

## 유닛 능력치

| 능력치 | 설명 |
|--------|------|
| 공격력 | 타격 피해량 |
| 체력 | 생명력 |
| 공격속도 | 공격 주기 |
| 사거리 | 공격 거리 |
| 범위 | 단일/스플래쉬 |

---

## 던전 유닛 베이스

### 아군 유닛
- 베이스 능력치에 콘텐츠(유물, 스킬) 능력치 합산
- 모든 공격 범위는 FALSE (단일 공격)

### 최종 능력치 계산
```
최종 능력치 = 베이스 능력치 + 스킬 보너스 + 유물 보너스 + 특성 보너스
```
