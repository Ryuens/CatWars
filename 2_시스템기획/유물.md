# 유물 시스템

## 개요
유물을 수집하고 강화하여 전체 유닛의 능력치를 영구적으로 증가시키는 시스템.

---

## 핵심 특징

- 유물 소환으로 획득
- 중복 획득 시 자동 강화
- 전체 유닛에 효과 적용
- 영구 성장 시스템

---

## 유물 강화 시스템

### 자동 강화 (중복 획득)
```
동일 유물 획득 시 자동으로 레벨업

레벨업 필요 개수:
Lv 1→2: 1개
Lv 2→3: 2개
Lv 3→4: 3개
...
Lv 99→100: 99개

총 필요 개수: 4,950개
```

### 레벨별 효과 증가
| 레벨 | 효과 배율 | 누적 개수 |
|------|----------|----------|
| 1 | 1.00x | 0 |
| 10 | 1.50x | 45 |
| 25 | 2.25x | 300 |
| 50 | 3.50x | 1,225 |
| 75 | 4.75x | 2,775 |
| 100 | 6.00x | 4,950 |

## 밸런스 설계

### 유물 영향력
```
[목표]
전체 전투력에서 유물 기여도: 30-40%

[예시: 만렙 전설 유물]
공격력 +72% (12% × 6배)
또는
체력 +72%
```

### 예상 획득 기간
```
만렙 전설 유물 1개: 약 6개월
모든 유물 전설: 약 3년+
```
