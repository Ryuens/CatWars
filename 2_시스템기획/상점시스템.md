# 상점 시스템

## 상품 유형 (ProductType)

| 유형 | 설명 |
|------|------|
| TIME_LIMITED | 구매 제한 시간이 있는 한정 상품 |
| LIMITED | 구매 가능 횟수 제한 상품 |
| CONSUMABLE | 반복 구매 가능 상품 (횟수 재충전) |
| AD_REWARD | 광고 보상형 상품 |
| MONTHLY_SUBSCRIPTION | 월간 구독 상품 |

---

## 상품 카테고리 (ProductCategory)

| 카테고리 | 설명 |
|----------|------|
| FULL_PACKAGE | 배너형 패키지 |
| GEM | 보석 상품 |

---

## 상점 데이터 구조

| 필드 | 설명 |
|------|------|
| ShopIdx | 상품 인덱스 |
| Order | 정렬 순서 |
| Service | 서비스 여부 |
| Visible | 노출 여부 |
| ValueMultiplier | 가치 배수 |
| ProductCategory | 상품 카테고리 |
| Name | 상품 이름 |
| ProductType | 상품 유형 |
| Value | 가격 |
