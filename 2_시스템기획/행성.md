# 타임라인 시스템

## 타임라인(타임라인) 레벨

- 총 300단계
- 타임라인 상승에 따른 난이도 증가
- PlanetLevel.xlsx에서 관리

---

## 시대 구조

### 기본 구조
- 시대 1~6 반복
- 6 이후 타임라인 이동 후 1~6 반복

### 진행 흐름
```
타임라인 1 → 시대 1~6 → 타임라인 2 → 시대 1~6 → 타임라인 3 → ...
```

---

## 난이도 시스템

### 난이도 적용
- 타임라인이 높아짐에 따라 난이도 상승
- 던전 적군 능력치에 난이도 배수 적용

### 난이도 계산
```
적군 공격력 = 베이스 공격력 × 타임라인 난이도
적군 체력 = 베이스 체력 × 타임라인 난이도
```

## 업그레이드 시스템

### 기지 업그레이드
- 레벨별 체력 증가 (최대 1000레벨)
- 레벨별 가격 증가
- 시대 1~6까지 / 6이후(타임라인 이동)이후 1~6 반복

### 소환석 업그레이드
- 생산량 증가
- SummonGemProduce.xlsx (1000단계)
