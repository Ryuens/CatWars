# 전투 시스템

## 기본 구조
- 맵 총 거리를 1로 기준
- 아군 기지 → 적군 기지 방향으로 유닛 소환
- 적군 기지 HP를 0으로 만들면 승리

---

## 전투 능력치

| 능력치 | 설명 |
|--------|------|
| 공격력 | 타격 시 적에게 주는 피해 |
| 체력 | 유닛의 생명력 |
| 공격속도 | n초마다 공격 (예: 0.7 = 0.7초마다 공격) |
| 사거리 | 맵 거리 비례 (0.5 = 맵의 절반 위치에서 공격 가능) |
| 범위 | FALSE = 단일 공격, TRUE = 스플래쉬 공격 |

### 사거리 예시

```
사거리 0.33: 맵의 1/3 위치에서 적 타워 공격 가능
사거리 0.5:  맵의 절반 위치에서 적 타워 공격 가능
사거리 0.66: 맵의 2/3 위치에서 적 타워 공격 가능
```

---

## 스파인 배속 계산

```
스파인 배속 = 1 / 공속
```

예시: 공속 0.7 → 스파인 배속 1.43

---

## 스테이지 웨이브

### 구조
- 시대 1~6 반복 (월드마다 반복)
- 웨이브 형식: `초 / 유닛index / 마릿수`

### 웨이브 카운팅
- 전 웨이브 기준으로 초 카운팅
- 예시:
  - Wave1: 8초 후 1번째 유닛 1마리
  - Wave8: 15초 후 3번째 유닛 2마리

---

## 골드 획득

### 유닛 처치
- 시대별, 유닛별 골드량 차등

### 적 기지 타격
- HP당 획득 골드 계산:
```
HP당 골드 = EnemyBaseCampGetGold / EnemyBaseCampHp
```
- 아군 유닛이 가격할 때마다 피해 HP에 비례해서 골드 획득
