# CatWars 게임 개요

## 게임 소개

CatWars는 고양이 종족들이 등장하는 타워 디펜스 기반 전략 게임입니다. 플레이어는 다양한 종족의 유닛을 소환하여 적군 기지를 파괴하고, 타임라인을 정복해 나갑니다.

---

## 코어 루프

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   전투 → 보상 획득 → 성장 → 더 강한 전투           │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 메인 루프

1. **전투 (Combat)**
   - 유닛 소환하여 적 기지 파괴
   - 골드/마석 획득
   - 스테이지 클리어

2. **성장 (Progression)**
   - 스킬 레벨업 & 초월
   - 유물 강화
   - 특성 업그레이드
   - 기지 업그레이드

3. **확장 (Expansion)**
   - 새로운 시대 진출
   - 타임라인 이동
   - 던전 도전

---

## 핵심 시스템 요약

### 1. 전투 시스템
- **목표**: 적군 기지 HP를 0으로
- **방식**: 유닛 자동 전투 + 스킬 사용
- **승리 조건**: 적 기지 파괴

### 2. 유닛 시스템
- 37개 종족, 각 종족당 3유닛
- 유닛별 공격력/체력/공속/사거리/범위 차별화
- 스테이지별 종족 배치

### 3. 성장 시스템

| 성장 요소 | 재화 | 효과 |
|-----------|------|------|
| 스킬 강화 | 스킬 재료 | 스킬 계수 증가 |
| 스킬 초월 | - | 추가 능력치 획득 |
| 특성 | 특성석 | 영구 스탯 증가 |
| 유물 | 유물 카드 | 전투 능력 강화 |
| 기지 | 골드 | 기지 HP 증가 |
| 소환석 | 골드 | 유닛 소환 속도 증가 |

### 4. 재화 시스템

| 재화 | 획득처 | 주요 용도 |
|------|--------|-----------|
| 골드 | 전투, 기지 타격 | 업그레이드, 유닛 해금 |
| 마석 | 퀘스트, 슬라임 던전 | 프리미엄 구매 |
| 특성석 | 마계침공 던전 | 특성 업그레이드 |
| 파랑수정 | 상점 | 특수 아이템 구매 |

## 콘텐츠 구조

### 메인 콘텐츠: 스테이지 진행
```
타임라인 1 → 시대 1~6 → 타임라인 2 → 시대 1~6 → ...
```
- 시대마다 6개 스테이지
- 각 스테이지별 웨이브 구성
- 타임라인(타임라인) 상승 시 난이도 증가

### 서브 콘텐츠: 던전

| 던전 | 목적 | 보상 |
|------|------|------|
| 슬라임 러쉬 | 마석 파밍 | 마석 |
| 마계침공 | 특성석 파밍 | 특성석 |

### 라이브 콘텐츠

- **배틀패스**: 120단계, Free/VIP 트랙
- **일일 퀘스트**: 11개 미션
- **출석 보상**: 7일 주기
- **룰렛**: 일일 보상

## 수익화 모델

### 상품 구조
1. **패키지**: 한정/제한 상품
2. **보석 상품**: 직접 구매
3. **광고 보상**: 무료 재화 획득
4. **월간 구독**: 정기 보상

### 주요 과금 포인트
- 스킬/유물 빠른 성장
- 배틀패스 VIP
- 한정 패키지

---

## 게임 특징

### 강점
- 다양한 종족과 유닛 조합
- 깊이 있는 성장 시스템
- 반복 플레이 보상 구조

### 핵심 재미 요소
- 유닛 조합 전략
- 스킬 빌드 최적화
- 성장에 따른 파워 증가 체감
- 던전 도전 및 클리어

---

## 타겟 유저

- **캐주얼 유저**: 자동 전투로 편한 플레이
- **미드코어 유저**: 스킬/유물 조합 최적화
- **하드코어 유저**: 던전 고층 도전, 랭킹 경쟁
