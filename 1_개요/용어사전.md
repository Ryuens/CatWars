# 용어 사전

CatWars 게임에서 사용되는 주요 용어를 정리합니다.

---

## 재화

| 용어 | 영문 | 설명 |
|------|------|------|
| 골드 | Gold | 기본 재화. 업그레이드, 유닛 해금에 사용 |
| 마석 | Gem | 프리미엄 재화. 상점 구매, 소환에 사용 |
| 파랑수정 | Blue Crystal | 특수 재화. 특정 아이템 구매에 사용 |
| 특성석 | Mastery Gem | 특성 업그레이드에 사용. 츄르박사의 실험실에서 획득 |
| 소환석 | Summon Gem | 유닛 소환에 사용하는 자원 (식량) |

---

## 유닛/종족

| 용어 | 영문 | 설명 |
|------|------|------|
| 종족 | Tribe | 3개 유닛으로 구성된 유닛 그룹 |
| 유닛 | Unit | 전투에 참여하는 개별 캐릭터 |
| 종족 인덱스 | Tribe Index | 종족을 구분하는 고유 번호 |
| 유닛 해금 | Unit Open | 골드를 사용하여 유닛 사용 가능하게 함 |
| 베이스 능력치 | Base Stat | 유닛의 기본 스탯 |

---

## 전투 능력치

| 용어 | 영문 | 설명 |
|------|------|------|
| 공격력 | Attack (ATK) | 타격 시 적에게 주는 피해량 |
| 체력 | Health (HP) | 유닛의 생명력 |
| 공격속도 | Attack Speed | n초마다 공격 (예: 0.7 = 0.7초마다) |
| 사거리 | Range | 맵 거리 비례 공격 거리 (0~1) |
| 범위 | Area | 공격 범위. FALSE=단일, TRUE=스플래쉬 |
| 스플래쉬 | Splash | 범위 공격. 여러 적에게 피해 |
| 스파인 배속 | Spine Speed | 애니메이션 속도. 1/공속으로 계산 |

---

## 스테이지/맵

| 용어 | 영문 | 설명 |
|------|------|------|
| 타임라인 | Planet | 타임라인. 시대 6개 클리어 후 이동 |
| 시대 | Continent/Age | 타임라인 내 스테이지 그룹 (1~6) |
| 스테이지 | Stage | 개별 전투 단계 |
| 웨이브 | Wave | 스테이지 내 적군 등장 단위 |
| 기지 | Base Camp | 아군/적군의 본진. HP가 0이 되면 패배 |

---

## 스킬

| 용어 | 영문 | 설명 |
|------|------|------|
| 스킬 | Skill | 전투에서 사용하는 능력 |
| 스킬 레벨 | Skill Level | 스킬의 강화 단계 |
| 스킬 계수 | Value | 레벨별 스킬 효과 수치 |
| 초월 | Transcendence | 스킬 최대 강화 후 추가 능력치 획득 |
| 1초월/2초월/3초월 | U1/U2/U3 | 초월 단계별 추가 능력치 |

---

## 특성

| 용어 | 영문 | 설명 |
|------|------|------|
| 특성 | Mastery | 영구 스탯 증가 시스템 |
| 특성 레벨 | Mastery Level | 특성의 강화 단계 |
| 특성 타입 | Mastery Type | 특성의 종류/카테고리 |

---

## 유물

| 용어 | 영문 | 설명 |
|------|------|------|
| 유물 | Artifact | 전투 능력 강화 아이템 |
| 유물 레벨 | Artifact Level | 유물의 강화 단계 |
| 유물 소환 | Artifact Summon | 유물을 획득하는 시스템 |
| 유물 카드 | Artifact Card | 유물 업그레이드에 필요한 재료 |

---

## 던전

| 용어 | 영문 | 설명 |
|------|------|------|
| 던전 | Dungeon | 보상 파밍용 특수 콘텐츠 |
| 악마 침공 | Demon Invasion | 마석 보상 던전 (500 스테이지) |
| 츄르박사의 실험실 | Dr.Chur Lab | 특성석 보상 던전 (1000 스테이지) |
| 챕터 | Chapter | 던전 내 난이도 구간 (10단위) |
| 던전 열쇠 | Dungeon Key | 던전 입장에 필요한 아이템 |

---

## 상점/상품

| 용어 | 영문 | 설명 |
|------|------|------|
| 패키지 | Package | 여러 아이템을 묶은 상품 |
| 한정 상품 | Time Limited | 구매 제한 시간이 있는 상품 |
| 소비성 상품 | Consumable | 반복 구매 가능한 상품 |
| 광고 보상 | Ad Reward | 광고 시청으로 얻는 보상 |
| 월간 구독 | Monthly Subscription | 정기 구독 상품 |
