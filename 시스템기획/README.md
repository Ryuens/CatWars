## 전투 시스템

### 기본 구조
- 맵 총 거리를 1로 기준
- 아군 기지 → 적군 기지 방향으로 유닛 소환
- 적군 기지 HP를 0으로 만들면 승리

### 전투 능력치

| 능력치 | 설명 |
|--------|------|
| 공격력 | 타격 시 적에게 주는 피해 |
| 체력 | 유닛의 생명력 |
| 공격속도 | n초마다 공격 (예: 0.7 = 0.7초마다 공격) |
| 사거리 | 맵 거리 비례 (0.5 = 맵의 절반 위치에서 공격 가능) |
| 범위 | FALSE = 단일 공격, TRUE = 스플래쉬 공격 |

### 스파인 배속 계산
- 공속 & 스파인 배속: `1 / 공속 = 스파인 배속`

### 스테이지 웨이브
- 대륙 1~6 반복 (월드마다 반복)
- 웨이브 형식: `초 / 유닛index / 마릿수`
- 전 웨이브 기준으로 초 카운팅

## 유닛 시스템

### 종족 구성
- 총 37개 종족
- 각 종족당 3개 유닛 구성
- 스테이지별 종족 인덱스 할당

### 유닛 해금
- **Unit2_OpenCost**: 스테이지별 유닛2번 해금 골드
- **Unit3_OpenCost**: 스테이지별 유닛3번 해금 골드
- **EvolutionCost**: 대륙 이동 비용

### 유닛 소환 비용
- 행성(타임라인)별 유닛 소환 비용 차등
- 대륙별, 유닛별 개별 비용 설정

## 스킬 시스템

### 스킬 구조
- 총 160개 스킬 (레벨별)
- 레벨별 계수(Value) 적용

### 스킬 초월
- **U1_Value**: 1초월 시 레벨별 능력치
- **U2_Value**: 2초월 시 레벨별 능력치
- **U3_Value**: 3초월 시 레벨별 능력치
- **Skill_U_StatType**: 초월 시 추가되는 능력치 타입

### 스킬 비용
- 레벨별 필요 스킬 재료량 설정

## 특성 시스템 (Mastery)

### 구조
- 총 95개 특성
- 760개 레벨 데이터
- 4개 특성 데이터 타입

### 특성석
- 마계침공 던전에서 획득
- 특성 업그레이드에 사용

## 던전 시스템

### 던전 종류

| 던전 | 보상 | 스테이지 |
|------|------|----------|
| 슬라임 러쉬 (Dr.Chur) | 마석 | 500 |
| 마계침공 | 특성석 | 1000 |

### 던전 구조
- 10인덱스마다 컨셉 변경 (챕터 구분)
- ~Idx 10: 챕터1, 11~20: 챕터2 ...

### 유닛 베이스
- **아군**: 베이스 능력치에 콘텐츠(유물, 스킬) 능력치 합산
- **적군**: 베이스 능력치 × 챕터 난이도
  - 공격력, 체력만 난이도 적용
  - 공격속도, 사거리, 스플래쉬는 고정

### 적군 등장
- 일정 시간마다 Enemy1부터 순차 등장
- Enemy1 모두 출현 → Enemy2 → Enemy3

## 경제 시스템

### 재화 종류

| 재화 | 용도 |
|------|------|
| 골드 | 유닛 해금, 업그레이드 |
| 마석 | 프리미엄 재화 |
| 파랑수정 | 특수 구매 |
| 특성석 | 특성 업그레이드 |

### 골드 획득
- **유닛 처치**: 대륙별, 유닛별 골드량
- **적 기지 타격**: HP당 획득 골드
  - `HP당 골드 = EnemyBaseCampGetGold / EnemyBaseCampHp`

### 업그레이드 시스템
- **기지 업그레이드**: 레벨별 체력/가격 (최대 1000레벨)
- **소환석 업그레이드**: 생산량 증가

## 상점 시스템

### 상품 유형

| 유형 | 설명 |
|------|------|
| TIME_LIMITED | 구매 제한 시간이 있는 한정 상품 |
| LIMITED | 구매 가능 횟수 제한 상품 |
| CONSUMABLE | 반복 구매 가능 상품 (횟수 재충전) |
| AD_REWARD | 광고 보상형 상품 |
| MONTHLY_SUBSCRIPTION | 월간 구독 상품 |

### 상품 카테고리
- **FULL_PACKAGE**: 배너형 패키지
- **GEM**: 보석 상품

### 배틀패스
- 120 단계
- Free/VIP 보상 분리

### 일일 보상
- 출석 보상: 7일 주기
- 일일 퀘스트: 11개 미션
- 룰렛: 8개 보상
