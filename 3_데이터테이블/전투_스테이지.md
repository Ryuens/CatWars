## StageSpawn.xlsx

스테이지 웨이브 정보 (6개)

### 컬럼

| 컬럼 | 설명 |
|------|------|
| Age | 스테이지 1~6 (월드마다 반복) |
| Wave | 초 / 유닛index / 마릿수 |

### 웨이브 형식
- 전 웨이브 기준으로 초 카운팅
- Wave1 기준 8초 후 1번째 유닛 1마리
- Wave8 기준 15초 후 3번째 유닛 2마리

---

## EnemyBaseCampHp.xlsx

스테이지별 적 기지 HP (600개)

### 용도
- 각 스테이지의 적군 기지 체력 정의

---

## EnemyBaseCampGetGold.xlsx

적 기지 타격 시 획득 골드 (6개)

### 컬럼

| 컬럼 | 설명 |
|------|------|
| EnemyBaseCampGetGold | 해당 스테이지에서 기지로 획득 가능한 골드 |

### 골드 계산
```
HP당 획득 골드 = EnemyBaseCampGetGold / EnemyBaseCampHp
```

### 구조
- 1~6대륙 획득량 (월드별 획득량은 반복)
