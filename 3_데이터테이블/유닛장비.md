## EquipmentLevel.xlsx

장비 레벨별 효과 데이터 (2000개 = 20장비 × 100레벨)

### 컬럼

| 컬럼 | 타입 | 설명 |
|------|------|------|
| Idx | int | 고유 ID |
| EquipmentIdx | string | 장비 ID (T1_01~T5_04) |
| Level | int | 레벨 (1~100) |
| LevelMultiplier | float | 레벨 효과 배율 |
| RequiredDuplicates | int | 다음 레벨 필요 중복 개수 |
| RequiredGold | int | 다음 레벨 필요 골드 |
| TotalDuplicates | int | 해당 레벨까지 누적 중복 개수 |
| TotalGold | int | 해당 레벨까지 누적 골드 |

### 레벨 계산 공식

```
레벨 배율 = 1.0 + (Level - 1) × 0.05
다음 레벨 필요 중복 = Level
다음 레벨 필요 골드 = Level × 1,000
누적 중복 개수 = Level × (Level - 1) / 2
누적 골드 = Level × (Level - 1) / 2 × 1,000
```

## 계산 공식

### 최종 효과 계산
```
최종 효과 = BaseValue × LevelMultiplier × StarMultiplier

예시: 전설 공격력 장비 (T5_01 고양이 왕의 전쟁 유물)
- 기본 효과: UNIT_DMG +25%
- Lv.100: 6.0x
- 5성: 2.5x
- 최종 효과: 25% × 6.0 × 2.5 = 375%
```

### 레벨업 필요 재료
```
중복 개수 = 현재 레벨
골드 = 현재 레벨 × 1,000

예: Lv.25 → Lv.26
- 중복 25개
- 골드 25,000
```

### 만렙까지 총 필요 재료
```
총 중복 개수 = 100 × 99 / 2 = 4,950개
총 골드 = 4,950 × 1,000 = 4,950,000
```

### 별 진화 비용
```
3★ → 4★: 상급석 15개 = 마법석 750개
4★ → 5★: 상급석 25개 = 마법석 1,250개
합계: 상급석 40개 = 마법석 2,000개
```

### 최종 완성 필요 재료
```
하나의 장비를 Lv.100 5★로 완성하려면:
- 중복 장비: 4,950개
- 골드: 4,950,000
- 마법석: 2,000개 (상급석 40개)
```

### 장비 최종 효과 계산
```csharp
// 장비 최종 효과 계산
float GetEquipmentFinalEffect(string equipmentIdx, int level, int star, int effectIndex)
{
    var equipment = GetEquipment(equipmentIdx);
    var levelData = GetEquipmentLevel(equipmentIdx, level);
    var starData = GetEquipmentStar(star);

    float baseValue = 0;
    switch (effectIndex)
    {
        case 1: baseValue = equipment.BaseValue1; break;
        case 2: baseValue = equipment.BaseValue2; break;
        case 3: baseValue = equipment.BaseValue3; break;
        case 4: baseValue = equipment.BaseValue4; break;
    }

    return baseValue * levelData.LevelMultiplier * starData.StarMultiplier;
}

// 예시: T5_01 고양이 왕의 전쟁 유물 Lv.100 5★
// BaseValue1 (ATK) = 25.0, LevelMultiplier = 6.0, StarMultiplier = 2.5
// 결과: 25.0 × 6.0 × 2.5 = 375%
```

### 장비 레벨업 (수동)
```csharp
// 장비 레벨업
bool LevelUpEquipment(string equipmentIdx)
{
    var playerEquipment = GetPlayerEquipment(equipmentIdx);
    var levelData = GetEquipmentLevel(equipmentIdx, playerEquipment.Level);

    if (playerEquipment.Level >= 100)
        return false;

    // 중복 개수 확인
    if (playerEquipment.DuplicateCount < levelData.RequiredDuplicates)
        return false;

    // 골드 확인
    if (playerData.Gold < levelData.RequiredGold)
        return false;

    // 레벨업
    playerEquipment.Level++;
    playerEquipment.DuplicateCount -= levelData.RequiredDuplicates;
    playerData.Gold -= levelData.RequiredGold;

    // 자동 별 진화 체크 (25레벨, 50레벨)
    if (playerEquipment.Level == 25 && playerEquipment.Star == 1)
        playerEquipment.Star = 2;
    else if (playerEquipment.Level == 50 && playerEquipment.Star == 2)
        playerEquipment.Star = 3;

    return true;
}
```

### 장비 별 진화 (수동)

```csharp
// 장비 별 진화
bool EvolveEquipmentStar(string equipmentIdx)
{
    var playerEquipment = GetPlayerEquipment(equipmentIdx);
    var evolutionData = GetEquipmentEvolution(playerEquipment.Star);

    if (evolutionData == null)
        return false; // 더 이상 진화 불가

    // 레벨 체크
    if (playerEquipment.Level < evolutionData.RequiredLevel)
        return false;

    // 상급석 체크
    if (playerData.SuperiorStone < evolutionData.RequiredSuperiorStone)
        return false;

    // 진화
    playerEquipment.Star++;
    playerData.SuperiorStone -= evolutionData.RequiredSuperiorStone;

    return true;
}
```

```csharp
// 유닛당 1개 장비 장착
bool EquipToUnit(int unitIdx, string equipmentIdx)
{
    var unit = GetUnit(unitIdx);
    var equipment = GetPlayerEquipment(equipmentIdx);

    if (equipment == null)
        return false;

    // 기존 장비가 있다면 해제
    if (unit.EquippedItem != null)
    {
        UnequipFromUnit(unitIdx);
    }

    // 새 장비 장착
    unit.EquippedItem = equipmentIdx;
    unit.EquipmentLevel = equipment.Level;
    unit.EquipmentStar = equipment.Star;

    // 스탯 적용
    ApplyEquipmentStats(unitIdx);

    return true;
}

// 스탯 적용
void ApplyEquipmentStats(int unitIdx)
{
    var unit = GetUnit(unitIdx);

    if (unit.EquippedItem == null)
        return;

    var equipment = GetEquipment(unit.EquippedItem);

    // 효과 1~4 적용
    for (int i = 1; i <= 4; i++)
    {
        int effectType = GetEffectType(equipment, i);
        if (effectType == 0) continue;

        float effectValue = GetEquipmentFinalEffect(unit.EquippedItem, unit.EquipmentLevel, unit.EquipmentStar, i);
        ApplyStatBonus(unit, effectType, effectValue);
    }
}

void ApplyStatBonus(Unit unit, int effectType, float value)
{
    switch (effectType)
    {
        case 1: // 공격력
            unit.BonusAttack += value;
            break;
        case 2: // 체력
            unit.BonusHealth += value;
            break;
        case 3: // 방어력
            unit.BonusDefense += value;
            break;
        case 4: // 공격속도
            unit.BonusAttackSpeed += value;
            break;
        case 5: // 치명타 확률
            unit.BonusCritRate += value;
            break;
        case 6: // 치명타 피해
            unit.BonusCritDamage += value;
            break;
        case 7: // 이동속도
            unit.BonusMoveSpeed += value;
            break;
        case 8: // 스킬 피해
            unit.BonusSkillDamage += value;
            break;
        case 9: // 쿨타임 감소
            unit.BonusCooldownReduction += value;
            break;
        case 10: // 피해 감소
            unit.BonusDamageReduction += value;
            break;
        case 11: // 회피
            unit.BonusDodge += value;
            break;
        case 12: // 마나
            unit.BonusMana += value;
            break;
        case 13: // 힐링
            unit.BonusHealing += value;
            break;
    }
}
```

```csharp
void OnSummon()
{
    playerData.PityCount++;

    // 천장 확인 (100회 먼저 체크)
    if (playerData.PityCount >= 100)
    {
        // 전설 확정

        return;

    else if (playerData.PityCount >= 50)

        // 영웅 확정 (50회마다)
        if (playerData.PityCount % 50 == 0)
        {
            GiveGuaranteedEquipment(4);
            return;
        }
    }

    GiveRandomEquipment();
}
```
