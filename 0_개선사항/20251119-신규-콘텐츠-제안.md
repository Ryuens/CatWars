# 신규 콘텐츠 제안

## 개요
현재 시스템 분석을 바탕으로 추가할 수 있는 신규 콘텐츠를 제안합니다.

---

## 1. PvP 콘텐츠

### 현재 상태
- PvE 콘텐츠만 존재
- 스테이지 진행, 던전

### 개선 목표
- 유저 간 경쟁 요소 추가
- 장기 리텐션 향상

### 상세 내용
- **실시간 PvP**: 1:1 대전
- **비동기 PvP**: 녹화된 유닛 구성으로 대전
- **랭킹 시스템**: 시즌별 보상

### 필요 데이터
- PvP 보상 테이블
- 랭킹 구간별 보상
- 매칭 풀 설정

### 우선순위
- [x] 높음

---

## 2. 길드 시스템

### 현재 상태
- 개인 플레이만 가능

### 개선 목표
- 소셜 요소 추가
- 협동 콘텐츠

### 상세 내용
- **길드 생성/가입**
- **길드 던전**: 협동 보스 레이드
- **길드 상점**: 길드 재화로 구매
- **길드 버프**: 공통 버프 효과

### 필요 데이터
- 길드 레벨 테이블
- 길드 던전 보스 스탯
- 길드 상점 아이템
- 길드 버프 효과

### 우선순위
- [x] 중간

---

## 3. 장비 시스템

### 현재 상태
- 유물, 스킬, 특성으로 성장
- 장비 개념 없음

### 개선 목표
- 추가 성장 축
- 파밍 콘텐츠 확장

### 상세 내용
- **장비 종류**: 무기, 방어구, 악세서리
- **등급 시스템**: 일반 ~ 전설
- **옵션 랜덤**: 재미 요소
- **강화/제련**: 골드 싱크

### 필요 데이터
- 장비 기본 스탯
- 등급별 옵션 풀
- 강화 확률/비용
- 드롭 테이블

### 우선순위
- [ ] 낮음

---

## 4. 이벤트 시스템 확장

### 현재 상태
- 배틀패스, 일일 보상

### 개선 목표
- 정기 이벤트로 복귀 유도
- 시즌 콘텐츠

### 상세 내용
- **주간 이벤트**: 특정 던전 보상 증가
- **월간 이벤트**: 한정 보스, 한정 보상
- **시즌 이벤트**: 테마별 스킨, 유닛

### 필요 데이터
- 이벤트 일정 테이블
- 이벤트 보상 테이블
- 한정 아이템 정의

### 우선순위
- [x] 중간
