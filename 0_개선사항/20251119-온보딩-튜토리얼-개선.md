# 온보딩 및 튜토리얼 개선

## 개요
초반 유저 이탈을 방지하기 위한 온보딩 UX 개선안

---

## 현재 문제점

### 1. 시각적 안내 부재
- 소환석(붕어빵) 시스템 설명 없음
- 유닛 생성 방법을 모름
- 터치해도 반응 없어서 버그로 오인

### 2. 게임 종료 메시지 이해 불가
- "신규 고양이를 데려 오세요" - 어디서?
- "업그레이드를 해보세요" - 무엇을?
- "유물, 스킬, 특성을 연구해 보세요" - 처음 듣는 용어

### 3. 로딩 시간 문제
- 미니앱인데 시작까지 10초 소요
- 잠깐 플레이하는 유저에게 허들

---

## 개선안

### 1. 첫 플레이 튜토리얼

#### 소환석 가이드 (최우선)
```
[화면 구성]
1. 소환석 게이지 하이라이트
2. "소환석이 채워지면 유닛을 소환할 수 있어요!" 말풍선
3. 게이지 가득 차면 유닛 버튼 반짝임
4. "터치해서 고양이를 소환하세요!" 안내
5. 첫 소환 성공 시 축하 이펙트
```

#### 단계별 튜토리얼 흐름
1. **1-1 스테이지**: 소환석 → 유닛 소환
2. **1-2 스테이지**: 2번째 유닛 해금
3. **1-3 스테이지**: 3번째 유닛 해금
4. **대륙 클리어**: 진화 개념 설명

### 2. 게임 종료 메시지 개선

#### Before
```
"유물, 스킬, 특성을 연구해 보세요"
```

#### After
```
[상황별 맞춤 메시지]

해금 전:
"스테이지 10을 클리어하면 스킬이 해금됩니다!"
"조금만 더 진행하면 유물을 획득할 수 있어요!"

해금 후:
"스킬 탭에서 '불꽃 발사'를 강화해보세요!" (구체적 스킬명)
"새로운 유물 '용의 발톱'을 장착하세요!" (구체적 유물명)

진화 가능:
"진화하면 더 강력한 고양이를 만날 수 있어요!"
"진화 비용: 골드 1,000" (구체적 수치)
```

### 3. 로딩 최적화

#### 기술적 개선
- 에셋 사전 로딩 (Pre-loading)
- 초기 필수 데이터만 우선 로드
- 백그라운드 로딩 적용

#### UX 개선
- 로딩 중 팁 표시
  - "소환석이 가득 차면 터치!"
  - "유닛마다 사거리가 달라요"
- 로딩 프로그레스 바 표시
- 예상 대기 시간 표시

### 4. 인게임 도움말

#### 물음표(?) 버튼 추가
- 각 UI 요소 옆에 도움말 버튼
- 터치 시 해당 기능 설명 팝업

#### 용어 사전 연동
- 게임 내 용어 터치 시 설명 표시
- 예: "특성" 터치 → "특성석으로 영구 강화하는 시스템입니다"
