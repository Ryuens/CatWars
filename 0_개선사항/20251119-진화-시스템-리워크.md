# 진화 시스템 리워크

## 개요
원점 회귀로 인한 피로감을 해소하고, 성장 체감을 유지하는 진화 시스템 개선안

---

## 현재 문제점

### 1. 원점 회귀 피로감
- 1-1 → 1-6 → 2-1 (신석기로 돌아감)
- 우주시대까지 성장시킨 노력이 리셋되는 느낌
- "노가다"처럼 느껴짐

### 2. 성장 연속성 단절
- 시대 변경 시 유닛 스탯 초기화
- 이전 시대 투자가 무의미하게 느껴짐

### 3. 콘텐츠 부족
- 진화해도 같은 패턴 반복
- 새로운 재미 요소 없음

---

## 개선안

### 1. 영구 장착 유물 시스템 (위아워리어 참고)

#### 개념
- 진화해도 초기화되지 않는 "영구 유물" 추가
- 유닛 슬롯에 장착하여 영구 버프 적용

#### 시스템 구조
```
[진화 시]
1. 진화 재화 "별의 조각" 획득
2. 별의 조각으로 영구 유물 소환
3. 영구 유물을 유닛 슬롯에 장착
4. 진화 후에도 효과 유지

[영구 유물 예시]
- 고대의 검: 1번 유닛 공격력 +5%
- 수호의 방패: 2번 유닛 체력 +10%
- 신속의 부츠: 3번 유닛 공격속도 +3%
```

#### 장착 UI
```
┌─────────────────────┐
│  [유닛 1]           │
│  ┌───┐              │
│  │🗡️│ 고대의 검 Lv.3│
│  └───┘              │
│  공격력 +15%        │
└─────────────────────┘
```

### 2. 진화 보상 강화

#### 현재
- 진화 시 골드만 소모

#### 개선
```
[진화 보상]
- 별의 조각 x10
- 마석 x50
- 영구 유물 소환권 x1
- 이전 시대 유닛 스킨 해금

[진화 마일스톤]
- 5회 진화: 전설 영구 유물 선택권
- 10회 진화: 전용 칭호 획득
- 20회 진화: 특별 스킨 세트
```

### 3. 시대 연속성 시스템

#### 유산 버프
- 클리어한 시대 수만큼 영구 버프
- 예: 신석기~우주 (6시대) 클리어 → 기본 스탯 +6%

#### 시대 마스터리
```
[신석기 마스터리]
- 1번 유닛 공격력 +2%
- 체력 +3%

[우주 마스터리]
- 모든 유닛 공격속도 +1%
- 소환석 생산 +5%
```

### 4. 시대 확장 (아트 중심)

#### 우주 이후 새로운 시대
- 사이버펑크 시대
- 마법 시대
- 신화 시대
- 미래 시대

#### 시대별 특징
- 고유 배경 아트
- 새로운 유닛 디자인
- 시대별 BGM
- 특수 이펙트

## 구현 우선순위

| 순위 | 항목 | 예상 효과 | 난이도 |
|------|------|----------|--------|
| 1 | 영구 유물 시스템 | 성장 연속성 | 높음 |
| 2 | 진화 보상 강화 | 진화 동기 부여 | 중간 |
| 3 | 시대 마스터리 | 반복 플레이 보상 | 중간 |
| 4 | 신규 시대 추가 | 콘텐츠 확장 | 높음 |

## 예상 효과

### 유저 경험
- 진화가 "리셋"이 아닌 "성장"으로 인식
- 장기 플레이 동기 부여
- 수집 요소 추가

### 수익화
- 영구 유물 소환 패키지
- 별의 조각 직접 구매
- 프리미엄 영구 유물

## 참고: 위아워리어 시스템

```
[위아워리어 진화 시스템]
1. 진화 시 "유물 조각" 획득
2. 유물 조각으로 "장착 유물" 소환
3. 장착 유물은 유닛 슬롯에 배치
4. 진화해도 장착 유물 효과 유지
5. 장착 유물 강화 시스템 존재
```
