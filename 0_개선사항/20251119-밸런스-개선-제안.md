# 밸런스 개선 제안

## 개요
현재 데이터 분석을 바탕으로 게임 밸런스 개선 포인트를 제안합니다.

---

## 1. 던전 난이도 곡선 조정

### 현재 상태
- 슬라임 러쉬: 500 스테이지
- 마계침공: 1000 스테이지
- 10단계마다 챕터 변경

### 개선 제안
- 초반 난이도 완화로 진입 장벽 낮추기
- 중반 난이도 급상승 구간 완화
- 후반 도전 콘텐츠로 하드코어 유저 만족

### 우선순위
- [x] 중간

---

## 2. 유닛 밸런스 재조정

### 현재 상태
- 113개 유닛 스탯
- 종족당 3유닛 고정 구성

### 개선 제안
- 유닛별 역할 명확화 (탱커, 딜러, 서포터)
- 사거리/범위에 따른 차별화 강화
- 초반/중반/후반 유닛 파워 곡선 조정

### 우선순위
- [x] 높음

---

## 3. 스킬 초월 시스템 확장

### 현재 상태
- 3단계 초월 (U1, U2, U3)
- 초월 시 추가 능력치만 제공

### 개선 제안
- 초월 단계별 시각적 효과 추가
- 4차 초월 이상 확장 검토
- 초월 스킬 특수 효과 추가

### 우선순위
- [ ] 낮음
