# 초반 콘텐츠 확장

## 개요
스킬/특성 해금 전 초반 구간에서 플레이할 수 있는 콘텐츠 추가

---

## 현재 문제점

### 1. 초반 콘텐츠 부족
- 스킬, 특성이 해금되기 전까지 할 것이 없음
- 유닛 소환 → 기지 파괴 반복만 존재
- 성장 체감 요소 부족

### 2. 해금 시점 문제
- 주요 기능이 후반에 몰려 있음
- 초반 유저가 게임의 재미를 느끼기 어려움

---

## 개선안

### 1. 초반 전용 미니 성장 시스템

#### 고양이 친밀도
```
[개념]
- 전투할수록 유닛 친밀도 상승
- 친밀도 레벨업 시 소소한 버프

[친밀도 보상]
Lv.1 → Lv.2: 공격력 +1%
Lv.2 → Lv.3: 체력 +1%
Lv.3 → Lv.4: 공격속도 +0.5%
...

[특징]
- 1-1부터 즉시 적용
- 스킬/특성과 별개의 성장축
- 시각적 이펙트 (하트, 이모지)
```

#### 유닛 강화 (간소화 버전)
```
[개념]
- 골드로 유닛 직접 강화
- 스킬 해금 전 골드 싱크

[강화 효과]
+1 강화: 공격력 +2%
+2 강화: 체력 +2%
+3 강화: 공격력/체력 +3%
...

[제한]
- 시대당 최대 +5까지
- 진화 시 유지 (영구 투자)
```

### 2. 초반 미션 시스템

#### 일일 목표 (초반 버전)
```
[1일차 미션]
□ 첫 번째 유닛 소환하기
□ 스테이지 1-1 클리어
□ 골드 100 모으기
→ 보상: 마석 x10

[2일차 미션]
□ 2번째 유닛 해금하기
□ 스테이지 1-3 클리어
□ 유닛 3마리 소환하기
→ 보상: 마석 x20

[3일차 미션]
□ 3번째 유닛 해금하기
□ 대륙 1 클리어
□ 진화하기
→ 보상: 마석 x50, 유물 소환권 x1
```

#### 업적 시스템
```
[전투 업적]
- 첫 승리: 마석 x5
- 10연승: 마석 x20
- 100 스테이지 클리어: 마석 x100

[수집 업적]
- 첫 유닛 해금: 골드 x500
- 모든 유닛 해금 (시대 1): 마석 x30
- 첫 진화: 유물 소환권 x1

[재화 업적]
- 골드 1,000 모으기: 마석 x10
- 골드 10,000 모으기: 마석 x50
```

### 3. 초반 보상 강화

#### 첫 클리어 보상
```
[스테이지별 첫 클리어 보상]
1-1: 골드 x100, 튜토리얼 완료
1-2: 골드 x200, 2번 유닛 해금 안내
1-3: 골드 x300, 3번 유닛 해금 안내
1-4: 골드 x400
1-5: 골드 x500
1-6: 마석 x10, 진화 안내
```

#### 연속 플레이 보상
```
[연속 전투 보너스]
3연전: 골드 +10%
5연전: 골드 +20%
10연전: 골드 +30% + 마석 x5
```

### 4. 초반 해금 콘텐츠 앞당기기

#### 해금 시점 조정
| 콘텐츠 | 현재 | 개선 |
|--------|------|------|
| 스킬 | 스테이지 ? | 1-6 클리어 (첫 진화) |
| 유물 | 스테이지 ? | 2-1 (두 번째 시대) |
| 특성 | 스테이지 ? | 2-6 클리어 (두 번째 진화) |
| 던전 | 스테이지 ? | 3-1 (세 번째 시대) |

#### 맛보기 체험
```
[스킬 맛보기]
- 1-3 클리어 시 임시 스킬 지급
- "화염 구슬" 3회 사용 가능
- 사용 후 "스킬을 해금하면 더 강력해져요!" 안내

[유물 맛보기]
- 1-6 클리어 시 임시 유물 지급
- 해당 스테이지에서만 효과 적용
- "유물을 해금하면 영구 장착!" 안내
```

### 5. 초반 시각적 피드백 강화

#### 성장 시각화
```
[유닛 강화 시]
- 유닛 주변 빛나는 이펙트
- 강화 단계별 색상 변화
- 수치 상승 애니메이션

[레벨업 시]
- 화면 전체 축하 이펙트
- "Level Up!" 텍스트
- 보상 획득 연출
```

#### 진행도 표시
```
[메인 화면]
┌─────────────────────┐
│ 현재: 신석기 1-3    │
│ ████████░░ 80%      │
│ 다음 해금: 스킬     │
│ 남은 스테이지: 3    │
└─────────────────────┘
```
