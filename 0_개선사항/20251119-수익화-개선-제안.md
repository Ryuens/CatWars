# 수익화 개선 제안

## 개요
현재 상점 시스템 분석을 바탕으로 수익화 개선 포인트를 제안합니다.

---

## 1. 패키지 구성 다양화

### 현재 상태
- 18개 상점 상품
- 25개 아이템 패키지
- 8개 저가 패키지

### 개선 제안

#### 초보자 패키지
- 첫 구매 할인 패키지
- 성장 부스트 아이템 포함

#### 복귀자 패키지
- 7일 이상 미접속 시 노출
- 현재 진행 상황에 맞는 아이템

#### 시즌 패키지
- 시즌별 한정 패키지
- FOMO 효과 활용

### 우선순위
- [x] 높음

---

## 2. 광고 수익화 확장

### 현재 상태
- AD_REWARD 상품 유형 존재
- 일일 퀘스트 광고 시청

### 개선 제안

#### 보상형 광고 확대
- 던전 입장권 추가 획득
- 클리어 보상 2배
- 소환 추가 기회

#### 광고 제거 상품
- 월정액 광고 제거
- 프리미엄 유저 혜택

### 우선순위
- [x] 중간

---

## 3. 구독 모델 강화

### 현재 상태
- MONTHLY_SUBSCRIPTION 유형 존재

### 개선 제안

#### 구독 등급 세분화
- **브론즈**: 기본 일일 보상
- **실버**: 추가 던전 입장권
- **골드**: VIP 전용 상점

#### 구독 혜택 차별화
- 자동 수집 기능
- 배속 플레이
- 전용 스킨

### 우선순위
- [x] 높음

---

## 4. 배틀패스 개선

### 현재 상태
- 120단계
- Free/VIP 트랙

### 개선 제안

#### 프리미엄 트랙 추가
- 3단계 트랙 (Free / VIP / Premium)
- Premium에 전용 스킨, 유닛

#### 시즌 테마
- 시즌별 테마 스킨
- 한정 수집 요소

#### 추가 구매
- 단계 스킵 구매
- 경험치 부스터

### 우선순위
- [x] 중간

---

## 5. 한정 판매 전략

### 현재 상태
- TIME_LIMITED, LIMITED 상품 유형 존재

### 개선 제안

#### 플래시 세일
- 시간 한정 대폭 할인
- 푸시 알림 연동

#### 번들 판매
- 2+1, 3+1 구성
- 대량 구매 유도

#### 첫 구매 보너스
- 첫 구매 시 추가 보상
- 과금 전환 유도

### 우선순위
- [x] 높음
