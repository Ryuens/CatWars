# 개선사항 관리

프로젝트 개선사항 및 확장 콘텐츠를 관리합니다.

---

## 작성 방법

### 파일명 규칙
```
YYYYMMDD-제목.md
```
예: `20251119-신규-던전-추가.md`

### 템플릿

```markdown
# 제목

## 개요
- 개선/추가할 내용 요약

## 현재 상태
- 현재 동작 방식

## 목표
- 달성하고자 하는 목표

## 상세 내용
- 구체적인 기획/구현 내용

## 필요 데이터
- 추가/수정할 데이터 테이블

## 우선순위
- [ ] 높음
- [ ] 중간
- [ ] 낮음

## 일정
- 예상 작업 기간

## 관련 문서
- 참고 문서 링크
```

---

## 상태 관리

| 상태 | 설명 |
|------|------|
| 기획중 | 아이디어 단계 |
| 검토중 | 기획 검토 진행 |
| 개발중 | 구현 진행 |
| 테스트 | QA 진행 |
| 완료 | 라이브 적용 |

---

## 카테고리

### 시스템 개선
- 기존 시스템 밸런스 조정
- UI/UX 개선
- 버그 수정

### 신규 콘텐츠
- 새로운 던전
- 신규 이벤트
- 추가 종족/유닛

### 수익화
- 신규 상품
- 패키지 구성
- 이벤트 상품

---

## 작업 흐름

1. **기획서 작성** → `개선사항/` 폴더에 문서 생성
2. **검토** → 팀 리뷰
3. **데이터 설계** → `데이터테이블/` 스펙 정의
4. **개발** → 구현
5. **테스트** → QA
6. **적용** → 문서 상태 업데이트
