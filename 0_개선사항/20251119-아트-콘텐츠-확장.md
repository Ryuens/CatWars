# 아트 기반 콘텐츠 확장

## 개요
배경과 캐릭터 아트 확장을 통한 시각적 재미 강화 및 콘텐츠 다양화

---

## 피드백 요약

> "냥냥이처럼 배경이랑 캐릭터 아트만 계속 공급해줘도 저는 재밌게 해볼거 같아요."
> "아트에 조금 더 중점을 두고 우주시대처럼 이후 시대를 계속 늘리는 방향"

---

## 개선안

### 1. 신규 시대 확장 (우주 이후)

#### 시대 로드맵
```
현재: 신석기 → 청동기 → 철기 → 중세 → 근대 → 우주

확장:
우주 → 사이버펑크 → 마법 → 신화 → 차원이동 → ???
```

#### 시대별 아트 컨셉

| 시대 | 배경 | 유닛 컨셉 | 컬러 톤 |
|------|------|-----------|---------|
| 사이버펑크 | 네온 도시 | 사이버 고양이 | 핑크/청록 |
| 마법 | 마법 숲 | 마법사 고양이 | 보라/금색 |
| 신화 | 올림푸스 | 신 고양이 | 흰색/금색 |
| 차원이동 | 차원 포탈 | 이차원 고양이 | 무지개색 |

### 2. 유닛 스킨 시스템

#### 스킨 종류
```
[기본 스킨]
- 시대별 기본 유닛

[프리미엄 스킨]
- 할로윈: 호박 고양이, 유령 고양이, 마녀 고양이
- 크리스마스: 산타 고양이, 루돌프 고양이, 눈사람 고양이
- 밸런타인: 큐피드 고양이, 하트 고양이

[전설 스킨]
- 황금 고양이
- 드래곤 고양이
- 천사 고양이
```

#### 스킨 획득 방법
- 이벤트 보상
- 시즌 배틀패스
- 상점 구매
- 업적 달성

### 3. 배경 커스터마이징

#### 배경 수집
```
[기본 배경]
- 시대별 기본 배경

[특별 배경]
- 벚꽃 배경 (봄 시즌)
- 해변 배경 (여름 시즌)
- 단풍 배경 (가을 시즌)
- 눈 배경 (겨울 시즌)

[프리미엄 배경]
- 황금 궁전
- 우주 정거장
- 마법 성
```

#### 배경 효과
- 일부 배경은 소소한 버프 제공
- 예: 벚꽃 배경 - 골드 획득 +3%

### 4. 이펙트 스킨

#### 공격 이펙트
```
[기본]
- 기본 타격 이펙트

[스킨]
- 하트 이펙트
- 별 이펙트
- 불꽃 이펙트
- 얼음 이펙트
```

#### 소환 이펙트
```
[기본]
- 기본 소환 연출

[스킨]
- 꽃잎 소환
- 번개 소환
- 마법진 소환
```

### 5. UI 테마

#### 테마 종류
```
[기본 테마]
- 기본 UI

[시즌 테마]
- 봄 테마: 파스텔 핑크
- 여름 테마: 시원한 블루
- 가을 테마: 따뜻한 오렌지
- 겨울 테마: 화이트/실버

[프리미엄 테마]
- 골드 테마
- 다크 테마
- 네온 테마
```

### 6. 아트 콘텐츠 업데이트 주기

#### 정기 업데이트
```
[월간]
- 신규 스킨 2~3개
- 신규 배경 1개

[시즌 (3개월)]
- 신규 시대 1개
- 시즌 스킨 세트
- 시즌 배경 세트

[연간]
- 대규모 아트 업데이트
- 기존 시대 리마스터
```

## 수익화 연계

### 스킨 상품
```
[단일 스킨]
- 일반 스킨: 500 마석
- 프리미엄 스킨: 1,000 마석
- 전설 스킨: 2,000 마석

[스킨 세트]
- 시즌 세트 (3종): 2,000 마석
- 시대 세트 (3종): 1,500 마석

[스킨 뽑기]
- 1회: 300 마석
- 10회: 2,700 마석
```

### 배틀패스 스킨
```
[시즌 배틀패스]
- Free 트랙: 일반 스킨 1개
- VIP 트랙: 프리미엄 스킨 2개 + 배경 1개
```

### 한정 판매
```
[시즌 한정]
- 할로윈 스킨 (10월만)
- 크리스마스 스킨 (12월만)
- FOMO 효과 활용
```

## 구현 우선순위

| 순위 | 항목 | 예상 효과 | 난이도 |
|------|------|----------|--------|
| 1 | 유닛 스킨 시스템 | 수집 재미, 수익화 | 중간 |
| 2 | 신규 시대 1개 | 콘텐츠 확장 | 높음 |
| 3 | 시즌 스킨/배경 | 정기 업데이트 | 중간 |
| 4 | 이펙트 스킨 | 시각적 만족 | 낮음 |
| 5 | UI 테마 | 커스터마이징 | 낮음 |

## 필요 리소스

### 아트 리소스
- 시대별 유닛 스프라이트 (3종 x 시대 수)
- 시대별 배경 이미지
- 스킨별 스프라이트
- 이펙트 스프라이트

### 데이터 테이블
- UnitSkin.xlsx - 유닛 스킨 정보
- Background.xlsx - 배경 정보
- Effect.xlsx - 이펙트 스킨
- UITheme.xlsx - UI 테마
