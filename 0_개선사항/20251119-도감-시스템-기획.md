# 도감 시스템 기획

## 개요
진화 및 유닛 획득 시 도감에 등록하고 보상을 받는 수집 시스템

---

## UI 위치

### 메뉴 구조
```
[우측 상단 메뉴 버튼]
├── 출석보상
├── 우편함
├── 도감 ← 신규 추가
└── 설정
```

---

## 도감 시스템 구조

### 1. 시대별 유닛 도감

#### 도감 등록 조건
- 해당 시대에서 유닛 해금 시 자동 등록
- 진화로 새 시대 진입 시 기본 유닛 등록

#### 도감 구조
```
┌─────────────────────────────────┐
│  [도감]                    X    │
├─────────────────────────────────┤
│  신석기  청동기  철기  중세  ... │
│  ━━━━━                          │
├─────────────────────────────────┤
│  ┌───┐  ┌───┐  ┌───┐           │
│  │🐱│  │🐱│  │❓│           │
│  └───┘  └───┘  └───┘           │
│  유닛1   유닛2   유닛3          │
│  ★★★    ★★☆    미획득         │
│                                 │
│  [시대 완성 보상]               │
│  ████████░░ 2/3                 │
│  보상: 마석 x100               │
└─────────────────────────────────┘
```

### 2. 등급 시스템

#### 유닛 등급
```
[등급 조건]
★☆☆ (1성): 유닛 해금
★★☆ (2성): 유닛으로 50 스테이지 클리어
★★★ (3성): 유닛으로 100 스테이지 클리어

[등급 보상]
1성 달성: 골드 x100
2성 달성: 마석 x10
3성 달성: 마석 x30
```

### 3. 도감 보상

#### 개별 유닛 보상
| 등록 | 보상 |
|------|------|
| 첫 등록 | 골드 x100 |
| 1성 | 골드 x100 |
| 2성 | 마석 x10 |
| 3성 | 마석 x30 |

#### 시대 완성 보상
```
[시대별 완성 보상]
신석기 완성 (3/3): 마석 x100
청동기 완성 (3/3): 마석 x150
철기 완성 (3/3): 마석 x200
중세 완성 (3/3): 마석 x250
근대 완성 (3/3): 마석 x300
우주 완성 (3/3): 마석 x500

[전체 완성 보상]
모든 시대 완성: 전설 스킨 선택권
```

#### 등급 완성 보상
```
[등급별 완성 보상]
모든 유닛 1성: 마석 x200
모든 유닛 2성: 마석 x500
모든 유닛 3성: 마석 x1000 + 칭호 "도감 마스터"
```

## 상세 기능

### 1. 유닛 상세 정보

#### 도감 상세 화면
```
┌─────────────────────────────────┐
│  [신석기 - 유닛1]          X    │
├─────────────────────────────────┤
│         ┌─────┐                 │
│         │ 🐱  │                 │
│         └─────┘                 │
│       "돌맹이 고양이"           │
│                                 │
│  [스탯]                         │
│  공격력: 10                     │
│  체력: 50                       │
│  공격속도: 1.0초                │
│  사거리: 0.3                    │
│  범위: 단일                     │
│                                 │
│  [설명]                         │
│  "신석기 시대의 용감한 전사.    │
│   돌로 만든 무기를 휘두른다."   │
│                                 │
│  [등급] ★★☆                    │
│  진행도: 72/100 스테이지        │
│  다음 보상: 마석 x30            │
└─────────────────────────────────┘
```

### 2. 도감 필터/정렬

#### 필터 옵션
- 전체
- 획득한 유닛
- 미획득 유닛
- 시대별

#### 정렬 옵션
- 시대순
- 등급순
- 획득순

### 3. 도감 알림

#### 알림 상황
```
[신규 등록]
"새로운 유닛이 도감에 등록되었습니다!"
→ 도감 버튼에 빨간 점 표시

[등급 상승]
"돌맹이 고양이가 2성이 되었습니다!"
→ 보상 수령 안내

[시대 완성]
"신석기 시대 도감을 완성했습니다!"
→ 완성 보상 수령 안내
```

### 4. 도감 공유

#### SNS 공유
```
[공유 이미지]
┌─────────────────────┐
│  CatWars 도감      │
│                     │
│  완성도: 80%        │
│  ████████░░         │
│                     │
│  총 유닛: 15/18     │
│  3성 유닛: 10       │
└─────────────────────┘

[공유 문구]
"나의 CatWars 도감 완성도는 80%!
3성 유닛 10마리 달성! 🐱"
```

## 확장 도감

### 1. 스킨 도감

#### 구조
```
[스킨 도감]
- 기본 스킨
- 이벤트 스킨
- 시즌 스킨
- 전설 스킨

[보상]
스킨 10개 수집: 마석 x100
스킨 50개 수집: 마석 x500
전설 스킨 전체 수집: 칭호 "패션왕"
```

### 2. 배경 도감

#### 구조
```
[배경 도감]
- 시대별 배경
- 시즌 배경
- 특별 배경

[보상]
배경 5개 수집: 마석 x50
배경 전체 수집: 프리미엄 배경 1개
```

### 3. 업적 도감

#### 구조
```
[업적 도감]
- 전투 업적
- 수집 업적
- 성장 업적
- 도전 업적

[보상]
업적 달성 시 개별 보상 + 도감 등록
```

## 데이터 설계

### 신규 테이블

#### Collection.xlsx
| 컬럼 | 설명 |
|------|------|
| CollectionIdx | 도감 인덱스 |
| Type | 유형 (유닛/스킨/배경) |
| RefIdx | 참조 인덱스 |
| Era | 시대 |
| Name | 이름 |
| Description | 설명 |

#### CollectionGrade.xlsx
| 컬럼 | 설명 |
|------|------|
| GradeIdx | 등급 인덱스 |
| Grade | 등급 (1/2/3) |
| Condition | 달성 조건 |
| ConditionValue | 조건 값 |

#### CollectionReward.xlsx
| 컬럼 | 설명 |
|------|------|
| RewardIdx | 보상 인덱스 |
| Type | 보상 유형 (개별/시대/전체) |
| Condition | 조건 |
| RewardItemIdx | 보상 아이템 |
| RewardAmount | 보상 수량 |

## 구현 우선순위

| 순위 | 항목 | 예상 효과 | 난이도 |
|------|------|----------|--------|
| 1 | 유닛 도감 기본 | 수집 재미 | 중간 |
| 2 | 등급 시스템 | 성장 목표 | 중간 |
| 3 | 시대 완성 보상 | 진행 동기 | 낮음 |
| 4 | 스킨/배경 도감 | 콘텐츠 확장 | 낮음 |
| 5 | SNS 공유 | 바이럴 마케팅 | 낮음 |

---

## 예상 효과

### 게임 플레이
- 수집 목표 제공
- 진화 동기 강화 (새 시대 유닛 등록)
- 장기 플레이 유도

### 유저 경험
- 성취감 (도감 완성)
- 자랑 (SNS 공유)
- 복기 (유닛 정보 확인)

### 수익화
- 스킨 구매 유도 (도감 완성)
- 빠른 진화 유도 (신규 유닛 등록)

---

## 연동 시스템

### 진화 시스템
- 진화 시 새 시대 유닛 자동 등록
- 도감 등록 보상이 진화 보상에 추가

### 스킨 시스템
- 스킨 획득 시 스킨 도감 등록
- 스킨 도감 완성 보상

### 업적 시스템
- 도감 관련 업적 추가
- "도감 수집가", "시대 마스터" 등
