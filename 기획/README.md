# CatWars 플레이어블 광고 기획서

## 개요

- **광고 플랫폼**: AppLovin
- **광고 유형**: 플레이어블 광고 (Playable Ad)
- **게임 장르**: 타워 디펜스 (We Are Warriors 유사)
- **파일 형식**: 단일 HTML5 파일
- **용량 제한**: 5MB 이하

---

## 기술 사양 (AppLovin 규격)

| 항목 | 요구사항 |
|------|----------|
| 파일 크기 | 5MB 이하 |
| 파일 형식 | 단일 HTML 파일 |
| 리소스 | Base64/Base122로 임베딩 |
| 외부 호출 | 금지 |
| MRAID | v2.0 지원 필수 |
| 화면 방향 | 가로/세로 모두 지원 |
| 오디오 | 첫 상호작용 전까지 음소거 |
| 리다이렉트 | 첫 탭에서 앱스토어 이동 금지 |

---

## 게임 기본 구조

### 전투 시스템
- 좌측: 아군 기지 (플레이어)
- 우측: 적군 기지 (AI)
- 유닛이 맵을 따라 이동하며 전투
- 적 기지 HP를 0으로 만들면 승리

### 웨이브 시스템
- 총 3 웨이브
- 각 웨이브마다 적 강화 (HP, 공격력 30% 증가)
- 각 웨이브마다 골드 획득량 증가 (3 → 4 → 5)

---

## 리소스 시스템

### 붕어빵 (유닛 소환용)

| 항목 | 값 |
|------|-----|
| 시작 보유량 | 3개 |
| 최대 보유량 | 20개 |
| 기본 생산량 | 1초당 1개 |
| 업그레이드 효과 | 생산량 +1 |

### 골드 (업그레이드/해금용)

| 항목 | 값 |
|------|-----|
| 시작 보유량 | 0 |
| 획득 방법 | 적 유닛 처치 |
| 웨이브별 획득량 | Wave1: 3 / Wave2: 4 / Wave3: 5 |

## UI 구성

### 상단 영역
- 좌측: 골드 보유량
- 우측: 현재 웨이브

### 게임 캔버스
- 배경: 하늘 + 잔디밭
- 좌측: 아군 성 (초록색)
- 우측: 적군 성 (빨간색)
- 유닛: 원형 + 이모지 아이콘

### 하단 패널
- 좌측: 붕어빵 게이지 + 업그레이드 버튼
- 중앙: 유닛 카드 3개

## 사용자 플로우

```
게임 시작
    │
    ▼
튜토리얼 손가락 표시 (첫 번째 카드)
    │
    ▼
유저 첫 유닛 소환
    │
    ▼
적 웨이브 시작
    │
    ▼
전투 진행 (유닛 소환, 업그레이드)
    │
    ▼
3회 상호작용 후 CTA 버튼 표시
    │
    ▼
게임 종료 (승리/패배)
    │
    ▼
최종 CTA 화면 → 앱스토어 이동
```

---

## 튜토리얼 가이드

1. **첫 실행**: 하단 첫 번째 유닛 카드에 손가락 아이콘 표시
2. **터치 유도**: 애니메이션으로 탭 동작 표현
3. **첫 탭 후**: 튜토리얼 손가락 숨김
4. **이후**: 자유 플레이

---

## CTA (Call to Action)

### 인앱 CTA 버튼
- **표시 조건**: 3회 이상 상호작용 후
- **위치**: 화면 하단 중앙 (카드 위)
- **텍스트**: "Play Now!"
- **동작**: 앱스토어로 이동

### 게임 종료 화면
- **승리 시**: "Victory!" + "Download Now!" 버튼
- **패배 시**: "Defeat!" + "Download Now!" 버튼

## 테스트 방법

### 로컬 테스트
```bash
cd /home/user/CatWars
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

### AppLovin 프리뷰
1. https://p.applov.in/playablePreview?create=1 접속
2. index.html 파일 업로드
3. 미리보기 확인
