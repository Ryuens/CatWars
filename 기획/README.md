# CatWars 플레이어블 광고 기획서 v2.0

## 개요

- **광고 플랫폼**: AppLovin
- **광고 유형**: 플레이어블 광고 (Playable Ad)
- **게임 장르**: 타워 디펜스 (We Are Warriors 스타일)
- **파일 형식**: 단일 HTML5 파일
- **용량 제한**: 5MB 이하
- **플레이 시간**: 30~45초 (Time-to-Fun < 10초)

---

## 핵심 디자인 원칙 (플레이어블 광고 베스트 프랙티스)

| 원칙 | 적용 방안 |
|------|-----------|
| **Time-to-Fun < 10초** | 게임 시작 즉시 유닛 소환 가능, 튜토리얼 최소화 |
| **초반 성공 경험** | 첫 웨이브 매우 쉽게 → 승리감 제공 |
| **점진적 긴장감** | 웨이브 진행시 적 강화, 내 기지 HP 낮게 설정 |
| **상시 CTA** | 화면에 항상 "지금 플레이" 버튼 노출 |
| **성장 체감** | 업그레이드 → 시대 진화 → 시각적 변화 |
| **단순한 조작** | 탭으로 소환, 탭으로 업그레이드 |

## 시대 진화 시스템 (핵심 신규 기능)

### 시대 목록

| 시대 | 시각적 테마 | 해금 조건 | 유닛 스타일 |
|------|-------------|-----------|-------------|
| **1. 원시시대** | 동굴, 나무 막대기 | 시작 | 원시 고양이 |
| **2. 고대시대** | 성벽, 검/방패 | 업그레이드 1회 | 검사 고양이 |
| **3. 중세시대** | 성, 갑옷/석궁 | 업그레이드 2회 | 기사 고양이 |

### 시대 진화 효과
- **기지 외형 변화**: 움막 → 목책 → 석조 성벽
- **유닛 외형 변화**: 원시복 → 갑옷 → 풀 아머
- **배경 변화**: 황무지 → 초원 → 문명화된 배경
- **효과음/이펙트**: 시대별 차별화

## 게임 기본 구조

### 전투 시스템
```
[아군 기지]  ←←←  유닛들이 이동하며 전투  →→→  [적군 기지]
   (좌측)              (중앙 전장)                (우측)
```

- 좌측: 아군 기지 (플레이어) - **낮은 HP로 긴장감 유발**
- 우측: 적군 기지 (AI)
- 유닛이 맵을 따라 이동하며 자동 전투
- 적 기지 HP를 0으로 만들면 승리

### 기지 체력 (긴장감 밸런스)

| 기지 | HP | 특징 |
|------|-----|------|
| **아군 기지** | 300 | 낮은 HP → 긴장감, "위기 극복" 경험 |
| **적군 기지** | 500 | 웨이브마다 다름, 점점 증가 |

## 웨이브 시스템 (난이도 곡선)

### 핵심: 초반 쉽게 → 점점 어렵게

| 웨이브 | 난이도 | 적 구성 | 적 강화 | 플레이어 경험 |
|--------|--------|---------|---------|---------------|
| **Wave 1** | 매우 쉬움 | 약한 적 2마리 | 없음 | 압도적 승리! 🎉 |
| **Wave 2** | 쉬움 | 적 3마리 | HP +20% | 여유로운 승리 |
| **Wave 3** | 보통 | 적 4마리 + 중간 보스 | HP/ATK +30% | 아슬아슬 승리 |
| **Wave 4** | 어려움 | 적 5마리 + 강한 보스 | HP/ATK +50% | 위기! → CTA 유도 |

### 웨이브별 상세

#### Wave 1 (승리 경험 제공)
- 적: 약한 고블린 2마리
- 목표: 플레이어가 "내가 잘하네!" 느끼게
- 골드 보상: 15

#### Wave 2 (성장 유도)
- 적: 고블린 3마리
- 튜토리얼: "업그레이드 해보세요!" 표시
- 골드 보상: 20

#### Wave 3 (긴장감)
- 적: 고블린 3마리 + 오크 2마리
- 플레이어 기지 살짝 위험해짐
- 골드 보상: 25

#### Wave 4 (클라이막스)
- 적: 오크 3마리 + 트롤 1마리
- 의도적으로 어렵게 → "더 강해지고 싶다!" → CTA
- 여기서 게임 종료 → 앱스토어 유도

```

├─────────────────────────────────────┤
│                                     │
│   [아군성]    전투영역    [적군성]    │  ← 게임 캔버스
│     HP바                   HP바      │
│                                     │
├─────────────────────────────────────┤
│        [ 지금 플레이! ]              │  ← CTA 버튼 (항상 표시)
├─────────────────────────────────────┤
│  ┌─────┐  ┌─────┐  ┌─────┐         │
│  │썸네일│  │썸네일│  │썸네일│   [🐟]  │  ← 유닛 카드 + 붕어빵
│  │ 30  │  │ 50  │  │ 80  │   245   │
│  ├─────┤  ├─────┤  ├─────┤         │
│  │업그레│  │업그레│  │업그레│         │  ← 업그레이드 버튼
│  │ 💰50│  │ 💰80│  │🔒   │         │
│  └─────┘  └─────┘  └─────┘         │
└─────────────────────────────────────┘
```

### 유닛 카드 (2단 구조)

```
┌───────────────┐
│   [썸네일]     │  ← 유닛 이미지
│               │
│    🐟 30      │  ← 소환 비용 (탭하면 소환)
├───────────────┤
│   업그레이드    │  ← 업그레이드 버튼
│    💰 50      │     (탭하면 강화)
└───────────────┘
```

### 상단 바
- 좌측: 골드 보유량 (💰 아이콘 + 숫자)
- 우측: 현재 웨이브 / 총 웨이브
- 중앙: 현재 시대 표시 (원시시대 → 고대시대 등)

### 하단 패널
- 유닛 카드 3개 (소환 + 업그레이드 버튼)
- 우측: 붕어빵 게이지 (원형, 노란색)

## 업그레이드 & 시대 진화

### 업그레이드 시스템

1. **개별 유닛 업그레이드**
   - 각 유닛 카드 아래 "업그레이드" 버튼
   - 골드 소모하여 해당 유닛 강화
   - 최대 2단계까지 (플레이어블 광고 내)

2. **시대 진화 트리거**
   - 총 업그레이드 횟수에 따라 시대 변화
   - 1회 업그레이드 → 고대시대 진화
   - 3회 업그레이드 → 중세시대 진화

### 시대 진화 연출

```
업그레이드 클릭
      │
      ▼
  화면 플래시
      │
      ▼
  기지 변신 애니메이션
      │
      ▼
  "고대시대 진입!" 텍스트
      │
      ▼
  유닛 외형 변화
```

## 튜토리얼 (최소화)

### 원칙: 10초 안에 플레이 시작

1. **첫 실행** (0~3초)
   - 게임 즉시 시작
   - 첫 번째 유닛 카드에 손가락 아이콘

2. **첫 소환 후** (3~10초)
   - 손가락 숨김
   - "적을 물리치세요!" 텍스트 (2초간)

3. **골드 획득 시**
   - 업그레이드 버튼에 손가락 아이콘 (1회만)

4. **이후**
   - 자유 플레이

## 밸런스 요약

### 플레이어 유리 요소
- 높은 초기 붕어빵 (100개)
- 빠른 붕어빵 생산 (초당 5개)
- 3개 유닛 모두 처음부터 활성화

### 긴장감 요소
- 낮은 기지 HP (300)
- Wave 4 강력한 적
- 시간 제한 (45초)

### 성장 체감 요소
- 업그레이드 → 시대 진화
- 시각적 변화 (기지, 유닛, 배경)
- 강해지는 유닛 스탯
