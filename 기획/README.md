# CatWars 플레이어블 광고 기획서 v2.1

## 개요

- **광고 플랫폼**: AppLovin
- **광고 유형**: 플레이어블 광고 (Playable Ad)
- **게임 장르**: 타워 디펜스
- **파일 형식**: 단일 HTML5 파일
- **용량 제한**: 5MB 이하
- **플레이 시간**: 30~45초

## UI 구성 상세

### 1. 상단 바

| 위치 | 요소 | 설명 |
|------|------|------|
| 좌측 상단 | 게임 타이틀 로고 | "CAT WARS" 로고 이미지 |
| 좌측 상단 | 플레이 버튼 (CTA) | 빨간색 버튼, 탭 시 앱스토어 이동 |
| 우측 상단 | 금화 표시 | 🪙 아이콘 + 획득한 금화 수량 |

### 2. 게임 영역

| 요소 | 설명 |
|------|------|
| 아군 기지 | 좌측, HP 바 표시 (400 HP) |
| 적 기지/영역 | 우측에서 적들이 나옴 |
| 전투 영역 | 중앙, 유닛들이 이동하며 전투 |
| 반짝이는 붕어빵 | 좌측 하단, 클릭하면 붕어빵 대량 획득 |

### 3. 하단 패널

| 요소 | 설명 |
|------|------|
| 유닛 카드 3개 | 소환/진화 버튼 포함 |
| 붕어빵 게이지 | 우측, 현재 보유량 표시 |

## 유닛 카드 시스템 (핵심)

### 카드 구조

```
┌────────────────┐
│     3/3        │ ← 소환 카운트 (현재/최대)
├────────────────┤
│                │
│   [유닛 썸네일] │ ← 유닛 이미지
│                │
├────────────────┤
│     진화       │ ← 3회 소환 완료 시 "진화" 버튼
│   (또는 🐟40)  │    미완료 시 "🐟 비용" 표시
```

```
│  🐟 40   │     │  🐟 40   │     │  🐟 40   │     │   진화    │ ← 파란색 버튼
└──────────┘     └──────────┘     └──────────┘     └──────────┘

                                                        ▼
```

## 진화 시스템

### 진화 조건
- 각 유닛을 **3회 소환**하면 "진화" 버튼 활성화
- 진화 버튼 클릭 시 해당 유닛의 시대 진화

### 진화 효과

| 항목 | 효과 |
|------|------|
| 유닛 스탯 | HP +30%, 공격력 +25% |
| 유닛 외형 | 시대에 맞게 변화 (원시 → 고대 → 중세) |
| 붕어빵 생산량 | +2/초 증가 |

### 시대 진화 단계

| 진화 단계 | 시대 | 유닛 외형 |
|-----------|------|-----------|
| 0단계 | 원시시대 | 막대기, 돌 |
| 1단계 | 고대시대 | 검, 방패 |
| 2단계 | 중세시대 | 갑옷, 석궁 |

## 붕어빵 시스템

### 기본 생산

| 항목 | 값 |
|------|-----|
| 시작 보유량 | 100개 |
| 최대 보유량 | 999개 |
| 기본 생산량 | 초당 3개 |

### 진화에 따른 생산량 증가

| 총 진화 횟수 | 생산량 |
|--------------|--------|
| 0회 (시작) | 3/초 |
| 1회 | 5/초 |
| 2회 | 7/초 |
| 3회 | 10/초 |
| 4회 이상 | +2/초씩 증가 |

## 반짝이는 붕어빵 (보너스)

### 출현 조건

| 조건 | 설명 |
|------|------|
| **게임 시작 시** | 첫 반짝이 붕어빵 출현 (횟수 미정) |
| **3유닛 모두 진화 시** | 모든 유닛이 진화 완료할 때마다 1회 출현 |

### 위치 및 동작
- **위치**: 좌측 하단 (기지 근처)
- **표시**: ✨ 반짝이는 이펙트 + 붕어빵 아이콘 + 획득량
- **동작**: 탭하면 표시된 수량만큼 붕어빵 즉시 획득
- **획득량**: 500개 (예시, 미정)

### 출현 타이밍

```
게임 시작
    │
    ▼
[✨ 반짝이 붕어빵 출현] ← 첫 번째
    │
    ▼
유닛 1, 2, 3 모두 1회씩 진화 완료
    │
    ▼
[✨ 반짝이 붕어빵 출현] ← 두 번째
    │
    ▼
유닛 1, 2, 3 모두 2회씩 진화 완료
    │
    ▼
[✨ 반짝이 붕어빵 출현] ← 세 번째
    ...
```

## 적 유닛 시스템

### 스폰 방식
- **산발적 등장**: 일정 간격으로 우측에서 적 유닛 스폰
- **무한 스폰**: 웨이브 개념 없이 지속적으로 등장

### 적 강화 조건

| 조건 | 적 유닛 변화 |
|------|--------------|
| 시작 | 약한 적 (고블린) |
| 유닛 1개 진화 완료 | 중간 적 추가 (오크) |
| 유닛 2개 진화 완료 | 강한 적 추가 (트롤) |
| 유닛 3개 모두 진화 | 보스급 적 등장 |

### 적 유닛 스탯

| 적 유닛 | HP | 공격력 | 이동속도 | 등장 조건 |
|---------|-----|--------|----------|-----------|
| 고블린 | 30 | 5 | 45 | 시작부터 |
| 오크 | 60 | 10 | 35 | 1회 진화 후 |
| 트롤 | 120 | 18 | 28 | 2회 진화 후 |
| 보스 | 200 | 25 | 20 | 3유닛 모두 진화 후 |

### 스폰 간격

| 진화 단계 | 스폰 간격 | 한번에 스폰 수 |
|-----------|-----------|----------------|
| 0회 진화 | 2초 | 1~2마리 |
| 1~2회 진화 | 1.5초 | 2~3마리 |
| 3회 이상 진화 | 1초 | 3~4마리 |

## 금화 시스템

### 획득 방법

| 방법 | 획득량 |
|------|--------|
| 적 유닛 처치 | 5~15 (적 종류에 따라) |
| 보스 처치 | 50 |

### 사용처
- 현재 기획에서는 **표시만** (소비 없음)
- 추후 업그레이드 등에 사용 가능

## CTA (Call To Action)

### 상시 CTA
- **위치**: 좌측 상단 (로고 아래)
- **텍스트**: "플레이" (빨간색 버튼)
- **동작**: 탭 시 앱스토어 이동

### 게임 종료 CTA
- **트리거**: 기지 HP 0 또는 일정 시간 경과
- **화면**: 전체 화면 오버레이
- **텍스트**: "지금 다운로드!"

## 게임 플로우

```
게임 시작
    │
    ▼
[✨ 반짝이 붕어빵 출현] → 탭하면 붕어빵 대량 획득
    │
    ▼
유닛 소환 시작 (손가락 튜토리얼)
    │
    ▼
적 산발적 등장 (약한 적)
    │
    ▼
유닛 3회 소환 → "진화" 버튼 활성화
    │
    ▼
진화 버튼 탭 → 시대 진화 연출
    │
    ▼
붕어빵 생산량 증가 + 더 강한 적 등장
    │
    ▼
3유닛 모두 진화 → [✨ 반짝이 붕어빵] + 보스 등장
    │
    ▼
반복... (점점 어려워짐)
    │
    ▼
기지 HP 0 또는 시간 종료
    │
    ▼
[게임 오버 화면] → CTA
```

## 밸런스 설정

### 플레이어 유리 요소
- 높은 초기 붕어빵 (100개)
- 반짝이 붕어빵으로 대량 획득 가능
- 진화할수록 붕어빵 생산량 증가

### 긴장감 요소
- 적 지속적 스폰 (쉴 틈 없음)
- 진화할수록 더 강한 적 등장
- 기지 HP 제한적 (400)

### 성장 체감
- 진화 시 유닛 외형 변화
- 진화 시 스탯 대폭 상승
- 붕어빵 생산량 증가
