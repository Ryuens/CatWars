# 게임 시스템 상세

## 1. 전투 시스템

### 1.1 맵 구조
```
[아군 기지] ◄──────── 전투 필드 ────────► [적군 기지]
    │                                         │
   HP: 100                                  HP: 100
```

- **맵 크기**: 화면 가로 전체
- **지면 높이**: 화면 하단에서 50px 위
- **기지 위치**: 좌측 60px / 우측 (화면폭 - 60px)

### 1.2 유닛 이동
- 아군: 좌측 → 우측 방향
- 적군: 우측 → 좌측 방향
- 이동 속도: 픽셀/초 단위

### 1.3 전투 로직
```
매 프레임:
1. 타겟 탐색 (가장 가까운 적)
2. 타겟이 사거리 내:
   - 이동 중지
   - 공격 쿨다운 확인
   - 쿨다운 완료 시 공격
3. 타겟이 사거리 밖:
   - 타겟 방향으로 이동
4. 타겟 없음:
   - 적 기지로 이동
   - 기지 사거리 내 도달 시 기지 공격
```

### 1.4 데미지 계산
- **기본 공식**: `타겟 HP -= 공격자 공격력`
- **웨이브 보너스**: 적 스탯 `* (1 + (웨이브 - 1) * 0.3)`

## 2. 리소스 시스템

### 2.1 붕어빵 시스템

#### 생산 메커니즘
```javascript
매 프레임:
  게이지 += deltaTime * 생산량
  if (게이지 >= 1):
    붕어빵 += 1
    게이지 = 0
```

#### 업그레이드
| 레벨 | 생산량 | 업그레이드 비용 |
|------|--------|----------------|
| 1 | 1/초 | - |
| 2 | 2/초 | 골드 5 |
| 3 | 3/초 | 골드 7 |
| 4 | 4/초 | 골드 10 |
| ... | ... | 비용 * 1.5 |

### 2.2 골드 시스템

#### 획득 경로
1. **적 유닛 처치**
   - Wave 1: 3골드/유닛
   - Wave 2: 4골드/유닛
   - Wave 3: 5골드/유닛

#### 사용처
- 붕어빵 생산량 업그레이드
- 잠긴 유닛 카드 해금

## 3. 유닛 시스템

### 3.1 아군 유닛

#### Warrior (전사)
```
타입: 근접
역할: 탱커/딜러
특징: 균형 잡힌 스탯
```

#### Archer (궁수)
```
타입: 원거리
역할: 딜러
특징: 높은 사거리, 낮은 체력
```

#### Mage (마법사)
```
타입: 원거리
역할: 고딜러
특징: 최고 공격력, 최저 체력
```

### 3.2 적 유닛

#### Goblin (고블린)
```
타입: 근접
등장: 전 웨이브
특징: 빠른 이동속도, 낮은 스탯
```

#### Orc (오크)
```
타입: 근접
등장: Wave 2+
특징: 높은 체력과 공격력
```

#### Troll (트롤)
```
타입: 근접
등장: Wave 3
특징: 보스급 스탯, 느린 속도
```

## 4. 웨이브 시스템

### 4.1 웨이브 진행

```
게임 시작
    │
    ├─ 2초 대기
    │
    ▼
Wave 1 시작
    │
    ├─ 적 스폰 (Goblin x3)
    ├─ 모든 적 처치
    │
    ▼
Wave 2 시작 (2초 대기)
    │
    ├─ 적 스폰 (Goblin x4, Orc x2)
    ├─ 모든 적 처치
    │
    ▼
Wave 3 시작 (2초 대기)
    │
    ├─ 적 스폰 (Goblin x5, Orc x3, Troll x1)
    ├─ 모든 적 처치
    │
    ▼
게임 종료 (승리)
```

### 4.2 스폰 규칙
- 동일 타입 유닛: 일정 간격(800ms)으로 스폰
- 다른 타입 유닛: 타입별 딜레이 후 스폰
- 웨이브 간 전환: 2초 대기

## 5. 승리/패배 조건

### 승리 조건
- 적 기지 HP ≤ 0

### 패배 조건
- 아군 기지 HP ≤ 0

### 게임 종료 처리
```javascript
if (적 기지 HP <= 0):
    종료 화면 표시 ("Victory!")
else if (아군 기지 HP <= 0):
    종료 화면 표시 ("Defeat!")

CTA 버튼 표시 ("Download Now!")
```

## 6. 밸런스 가이드라인

### 6.1 난이도 설계
- **Wave 1**: 쉬움 (튜토리얼 성격)
- **Wave 2**: 보통 (업그레이드 필요)
- **Wave 3**: 어려움 (전략적 플레이 필요)

### 6.2 예상 플레이 시간
- 최소: 30초 (빠른 패배)
- 평균: 60-90초
- 최대: 120초 (풀 플레이)

### 6.3 유저 경험 목표
1. 첫 10초: 간단한 조작 이해
2. 30초: 업그레이드 시스템 발견
3. 60초: 새 유닛 해금
4. 90초: CTA 버튼 인지
