## 4. 하단 패널

### 4.1 붕어빵 시스템
```
┌───────────┐
│   🐟      │  ← 아이콘 (28px)
│   3       │  ← 보유량 (14px)
│ ▓▓▓░░░░░  │  ← 게이지 (채워지는 중)
└───────────┘
 [⬆ 5 💰]     ← 업그레이드 버튼
```

#### 게이지 애니메이션
- 1초 동안 0% → 100%
- 완료 시 즉시 리셋
- 색상: 골드 그라디언트 (#FFD700 → #FFA500)

#### 업그레이드 버튼
- **활성화**: 초록 그라디언트
- **비활성화**: 회색, opacity 0.6

### 4.2 유닛 카드

#### 기본 구조
```
┌─────────────┐
│    😺       │  ← 유닛 아이콘 (40px)
│  Warrior    │  ← 유닛 이름 (10px)
│  [🐟 3]     │  ← 소환 비용
└─────────────┘
```
- **크기**: 75px x 95px
- **모서리**: 12px radius
- **간격**: 10px

#### 카드 상태

**활성화 상태**
- 테두리: 3px solid #4CAF50
- 그림자: 0 0 15px rgba(76,175,80,0.5)
- 터치 시: scale(0.95)

**잠금 상태**
- opacity: 0.5
- 자물쇠 아이콘 오버레이
- 하단에 해금 비용 표시

**비용 부족**
- opacity: 0.6
- 터치 반응 없음

## 5. 튜토리얼 손가락

### 5.1 디자인
```
      ╭───╮
      │   │
      │   │
   ╭──┤   ├──╮
   │  │   │  │
   ╰──┴───┴──╯
        ●      ← 그림자
```
- **크기**: 50px x 50px
- **색상**: 피부색 (#FFDAB9)
- **그림자**: 타원형, rgba(0,0,0,0.3)

### 5.2 애니메이션
```css
@keyframes fingerTap {
    0%, 100%: translate(0, 0) scale(1), opacity 1
    50%: translate(0, 10px) scale(0.9), opacity 0.8
}
```
- **주기**: 1초
- **이징**: ease-in-out

### 5.3 위치
- 첫 번째 유닛 카드 위
- 카드 중앙에서 25px 왼쪽, 30px 위

## 9. 반응형 설계

### 9.1 화면 크기 대응
```javascript
// 캔버스 크기 조절
canvasWidth = container.clientWidth
canvasHeight = container.clientHeight - 130  // 하단 패널

// 기지 위치 재계산
playerBaseX = 60
enemyBaseX = canvasWidth - 60
groundY = canvasHeight - 50
```

### 9.2 방향 전환
- `orientationchange` 이벤트 감지
- 100ms 딜레이 후 리사이즈
- 모든 위치값 재계산
